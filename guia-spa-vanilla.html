Vanilla JS · HTML · CSS

Una arquitectura modular basada en Web Components nativos donde cada página es un componente registrado, el router es el único orquestador y añadir una nueva ruta es escribir un único archivo. Sin React, sin Vue, sin Webpack. Solo la plataforma.

El contrato de la arquitectura: cada página es un Web Component que vive en pages/. El router lee el hash de la URL, importa el componente dinámicamente y lo monta en <main>. Añadir una página = crear un archivo. Nada más.
Visión general del sistema
La SPA tiene tres responsabilidades separadas: el shell HTML estático que nunca cambia, el router que escucha la URL, y los page components que se montan y desmontan solos.

Anatomía de un Web Component
Un Web Component es una clase que extiende HTMLElement y se registra con customElements.define(). Tiene un ciclo de vida propio: connectedCallback (montado) y disconnectedCallback (desmontado).
components/app-nav.js — Componente de navegación con Shadow DOM
JavaScript
// Cada componente es un archivo independiente
class AppNav extends HTMLElement {

  // Shadow DOM aísla los estilos del componente
  constructor() {
    super();
    this._shadow = this.attachShadow({ mode: 'open' });
  }

  // Se ejecuta al insertar el elemento en el DOM
  connectedCallback() {
    this._render();
    this._bindEvents();
  }

  // Se ejecuta al retirar el elemento del DOM
  disconnectedCallback() {
    // Limpia event listeners, timers, subscripciones
    this._cleanup?.();
  }

  _render() {
    this._shadow.innerHTML = `
      <style>
        nav { display: flex; gap: 1rem; padding: 1rem; }
        a { color: inherit; text-decoration: none; }
        a.active { font-weight: bold; }
      </style>
      <nav>
        <a href="#/">Inicio</a>
        <a href="#/about">Sobre mí</a>
        <a href="#/contact">Contacto</a>
      </nav>
    `;
  }

  _bindEvents() {
    // Marcar el link activo al cambiar la ruta
    const markActive = () => {
      const hash = location.hash || '#/';
      this._shadow.querySelectorAll('a').forEach(a => {
        a.classList.toggle('active', a.getAttribute('href') === hash);
      });
    };
    window.addEventListener('hashchange', markActive);
    markActive();
    this._cleanup = () => window.removeEventListener('hashchange', markActive);
  }
}

// Registro: el nombre debe contener un guion
customElements.define('app-nav', AppNav);
Shadow DOM vs Light DOM
Cuándo usar Shadow DOM: componentes UI con estilos propios (nav, modal, card). Cuándo evitarlo: páginas completas — el Shadow DOM impide que los estilos globales lleguen al contenido.

Shadow DOM Componentes

Encapsula estilos. Ideal para <app-nav>, <app-modal>, <ui-card>. Los estilos no se filtran ni hacia dentro ni hacia afuera.

Light DOM Páginas

Sin Shadow DOM. Las páginas (<page-home>) usan this.innerHTML directamente. Reciben los estilos globales del global.css.

Atributos reactivos Avanzado

Usa observedAttributes y attributeChangedCallback para que el componente reaccione a cambios en sus atributos HTML como si fueran props.

Atributos reactivos — componente con "props"
JavaScript
class UserCard extends HTMLElement {

  // Declara qué atributos quieres observar
  static get observedAttributes() {
    return ['name', 'avatar'];
  }

  // Se ejecuta cuando cambia un atributo observado
  attributeChangedCallback(name, oldVal, newVal) {
    if (oldVal !== newVal) this._render();
  }

  connectedCallback() { this._render(); }

  _render() {
    const name   = this.getAttribute('name')   || 'Anónimo';
    const avatar = this.getAttribute('avatar') || '/default.png';
    this.innerHTML = `
      <div class="user-card">
        <img src="${avatar}" alt="${name}" />
        <span>${name}</span>
      </div>
    `;
  }
}

customElements.define('user-card', UserCard);

// Uso en HTML: <user-card name="Ana" avatar="/ana.jpg"></user-card>
El router basado en hash
Por qué hash (#) y no History API: el hash funciona sin servidor. Con History API necesitas configurar el servidor para que devuelva siempre index.html. Para empezar, el hash es cero fricción.
router.js — El corazón de la SPA
JavaScript
/**
 * router.js
 * ─────────────────────────────────────────────
 * - Lee window.location.hash
 * - Importa el módulo de página dinámicamente
 * - Monta el componente en el outlet <main>
 * - Soporta params: #/user/:id → { id: '42' }
 */

const routes = [
  { path: '/',        component: 'page-home',      module: './pages/home.js'      },
  { path: '/about',   component: 'page-about',     module: './pages/about.js'     },
  { path: '/contact', component: 'page-contact',   module: './pages/contact.js'   },
  { path: '/user/:id',component: 'page-user',      module: './pages/user.js'      },
  { path: '*',        component: 'page-not-found', module: './pages/not-found.js' },
];

const outlet = document.getElementById('outlet');

// ── Matching con soporte a parámetros ─────────────────────
function matchRoute(hash) {
  const path = hash.replace('#', '') || '/';

  for (const route of routes) {
    if (route.path === '*') continue;

    // Convierte '/user/:id' en regex '/user/([^/]+)'
    const pattern = route.path.replace(/:([^/]+)/g, '([^/]+)');
    const match   = path.match(new RegExp(`^${pattern}$`));

    if (match) {
      const keys   = [...route.path.matchAll(/:([^/]+)/g)].map(m => m[1]);
      const params = Object.fromEntries(keys.map((k, i) => [k, match[i + 1]]));
      return { ...route, params };
    }
  }
  return routes.find(r => r.path === '*'); // fallback 404
}

// ── Navegación ────────────────────────────────────────────
async function navigate() {
  const route = matchRoute(window.location.hash);

  // 1. Importar el módulo solo si no está ya registrado
  if (!customElements.get(route.component)) {
    await import(route.module);
  }

  // 2. Limpiar el outlet (activa disconnectedCallback)
  outlet.innerHTML = '';

  // 3. Crear y montar el componente
  const el = document.createElement(route.component);

  // 4. Pasar params como dataset: dataset.id, dataset.slug…
  if (route.params) {
    Object.entries(route.params).forEach(([k, v]) => {
      el.dataset[k] = v;
    });
  }

  outlet.appendChild(el);
}

// ── Inicialización ────────────────────────────────────────
window.addEventListener('hashchange', navigate);
navigate(); // carga inicial

El flujo de trabajo: añadir una página nueva
Son exactamente 2 pasos. No toques el router existente si ya funciona, no toques el index.html, no registres nada en main.js. Solo añade el archivo y la ruta.

Crea el archivo de página

Añade pages/blog.js con la clase del componente y su customElements.define().

Registra la ruta

Añade una entrada al array routes en router.js. Eso es todo.

Navega

Enlaza con href="#/blog" en la navegación. El router importa el módulo la primera vez que se visita.

pages/blog.js — plantilla base para cualquier página nueva
JavaScript
/**
 * pages/blog.js
 * Plantilla base — copia, renombra y personaliza.
 * ──────────────────────────────────────────────
 * CONVENCIONES:
 *   - Nombre del tag:  page-[nombre]   (siempre con guion)
 *   - Nombre de clase: Page[Nombre]    (PascalCase)
 *   - No usar Shadow DOM en páginas   (los estilos globales deben llegar)
 */

class PageBlog extends HTMLElement {

  connectedCallback() {
    // Leer params pasados por el router via dataset
    const page = this.dataset.page || '1';

    this._render(page);
    this._loadData(page);
  }

  disconnectedCallback() {
    // Cancelar fetches, limpiar intervalos, desuscribirse del store
    this._abortController?.abort();
  }

  _render(page) {
    this.innerHTML = `
      <section class="page page--blog">
        <h1>Blog</h1>
        <p class="page__subtitle">Página ${page}</p>
        <div id="blog-list" class="blog-list">
          <p>Cargando artículos…</p>
        </div>
      </section>
    `;
  }

  async _loadData(page) {
    this._abortController = new AbortController();

    try {
      const res  = await fetch(`/api/posts?page=${page}`, {
        signal: this._abortController.signal
      });
      const data = await res.json();
      this._renderPosts(data.posts);
    } catch (err) {
      if (err.name !== 'AbortError') {
        this.querySelector('#blog-list').innerHTML =
          '<p class="error">Error cargando artículos.</p>';
      }
    }
  }

  _renderPosts(posts) {
    const list = this.querySelector('#blog-list');
    list.innerHTML = posts.map(p => `
      <article class="post-card">
        <h2><a href="#/post/${p.id}">${p.title}</a></h2>
        <p>${p.excerpt}</p>
      </article>
    `).join('');
  }
}

customElements.define('page-blog', PageBlog);

Subpáginas y rutas anidadas
Patrón recomendado para subpáginas: una página padre actúa como mini-router interno usando un segundo outlet. La URL queda como #/settings/profile o #/settings/security.
pages/settings.js — página con sub-navegación interna
JavaScript
// Subrutas registradas en router.js:
// { path: '/settings',          component: 'page-settings', ... }
// { path: '/settings/:section', component: 'page-settings', ... }

class PageSettings extends HTMLElement {

  static subRoutes = {
    'profile'  : () => import('./settings/profile.js'),
    'security' : () => import('./settings/security.js'),
    'billing'  : () => import('./settings/billing.js'),
  };

  connectedCallback() {
    const section = this.dataset.section || 'profile';
    this._render(section);
    this._loadSection(section);
  }

  _render(active) {
    this.innerHTML = `
      <div class="settings-layout">
        <aside class="settings-nav">
          <a href="#/settings/profile"   class="${active==='profile'  ?'active':''}">Perfil</a>
          <a href="#/settings/security"  class="${active==='security' ?'active':''}">Seguridad</a>
          <a href="#/settings/billing"   class="${active==='billing'  ?'active':''}">Facturación</a>
        </aside>
        <main id="sub-outlet" class="settings-content">
          <p>Cargando…</p>
        </main>
      </div>
    `;
  }

  async _loadSection(section) {
    const loader = PageSettings.subRoutes[section]
                || PageSettings.subRoutes['profile'];

    await loader(); // importa el módulo si no está registrado

    const subOutlet = this.querySelector('#sub-outlet');
    subOutlet.innerHTML = '';
    subOutlet.appendChild(document.createElement(`settings-${section}`));
  }
}

customElements.define('page-settings', PageSettings);
Estado global mínimo
No necesitas Redux. Un objeto reactivo con suscriptores es suficiente para el 90% de los casos. Las páginas se suscriben en connectedCallback y se desuscriben en disconnectedCallback.
shared/store.js — estado reactivo sin dependencias
JavaScript
class Store {
  #state       = {};
  #subscribers = new Map();

  setState(slice) {
    this.#state = { ...this.#state, ...slice };
    // Notifica solo a los suscriptores de las claves cambiadas
    Object.keys(slice).forEach(key => {
      this.#subscribers.get(key)?.forEach(fn => fn(this.#state[key]));
    });
  }

  getState() { return { ...this.#state }; }

  subscribe(key, fn) {
    if (!this.#subscribers.has(key)) this.#subscribers.set(key, new Set());
    this.#subscribers.get(key).add(fn);
    return () => this.#subscribers.get(key).delete(fn); // retorna unsubscribe
  }
}

export const store = new Store();

Comunicación entre componentes

Props hacia abajo dataset

El router pasa datos a la página via el.dataset.id = value. La página los lee con this.dataset.id en connectedCallback.

Eventos hacia arriba CustomEvent

Un componente hijo dispara this.dispatchEvent(new CustomEvent('user-selected', { detail, bubbles: true })) y el padre lo escucha en el DOM.

Hermanos store / bus

Usa el store.js o un event bus para comunicar páginas o componentes que no tienen relación directa en el DOM.

shared/events.js — event bus simple
JavaScript

  bus.dispatchEvent(new CustomEvent(event, { detail }));

export const off   = (event, fn) => { bus.removeEventListener(event, fn); };

Transiciones entre páginas
Con la View Transitions API (Chrome 111+) tienes animaciones de página con 3 líneas de JS. El fallback para navegadores sin soporte es simplemente navegar sin animación.
router.js — navegación con View Transitions API
JavaScript
async function navigate() {
  const doNavigate = async () => {
    const route = matchRoute(window.location.hash);
    if (!customElements.get(route.component)) await import(route.module);
    outlet.innerHTML = '';
    const el = document.createElement(route.component);
    if (route.params) Object.entries(route.params)
      .forEach(([k, v]) => el.dataset[k] = v);
    outlet.appendChild(el);
  };

  // View Transitions API — animación nativa del browser
  if (document.startViewTransition) {
    document.startViewTransition(doNavigate);
  } else {
    await doNavigate();
  }
}

/* En global.css — personaliza la transición:
::view-transition-old(root) {
  animation: 200ms ease-out fade-out;
}
::view-transition-new(root) {
  animation: 300ms ease-in fade-in;
} */

export function setMeta({ title, description, canonical }) {
  if (title)       document.title = `${title} · Mi SPA`;
  if (description) {
    let meta = document.querySelector('meta[name="description"]');
    if (!meta) {
      meta = document.createElement('meta');
      meta.name = 'description';
      document.head.appendChild(meta);
    }
    meta.content = description;
  }
}
