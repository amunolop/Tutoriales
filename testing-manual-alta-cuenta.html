Caso de usoAlta de cuenta de usuario

El usuario rellena un formulario en la SPA con datos personales (nombre, email, DNI), cuenta (username), password (con confirmación) y expediente (número y tipo). El front valida localmente, envía un POST al API REST, el servlet recibe el JSON, el service aplica reglas de negocio y el DAO persiste en BD.

1 · Frontend SPA
Formulario JS
Valida email, password ≥ 8 chars, DNI con formato, campos obligatorios. Envía POST /api/cuentas con fetch.
→
2 · API REST
POST /api/cuentas
Contrato JSON: { nombre, email, dni, username, password, expediente }. Respuesta: 201 Created o 400/409.
→
3 · Backend
Servlet → Service → DAO
CuentaServlet parsea JSON. CuentaService valida duplicados, hashea password. CuentaDao inserta en BD.

Qué NO testear
✗ No:
• Getters/setters de Cuenta.java
• El propio Tomcat
• CSS del formulario
• console.log / Logger
• Librerías de terceros (BCrypt internals)
✓ Sí:
• Toda validación (front + back)
• Hash de password
• Cada status code del endpoint
• Duplicados (email, username)
• Formato JSON request/response
Unit Test del Service — lógica de negocio
Patrón GIVEN-WHEN-THEN: Prepara escenario → ejecuta acción → verifica resultado. El DAO está mockeado — solo testeas la lógica del Service.
// CuentaServiceTest.java — JUnit 5 + Mockito

@ExtendWith(MockitoExtension.class)
class CuentaServiceTest {

    @Mock private CuentaDao cuentaDao;
    @InjectMocks private CuentaService service;

    @Test
    void crear_conDatosValidos_guardaConPasswordHasheado() {
        // GIVEN
        AltaCuentaDto dto = new AltaCuentaDto(
            "Ana García", "ana@mail.com", "12345678A",
            "anagarcia", "Pass1234", "EXP-001", "Premium"
        );
        when(cuentaDao.existsByEmail("ana@mail.com")).thenReturn(false);
        when(cuentaDao.existsByUsername("anagarcia")).thenReturn(false);
        when(cuentaDao.save(any())).thenAnswer(i -> {
            Cuenta c = i.getArgument(0);
            c.setId(1L);
            return c;
        });

        // WHEN
        Cuenta result = service.crear(dto);

        // THEN
        assertNotNull(result.getId());
        assertEquals("ana@mail.com", result.getEmail());
        assertNotEquals("Pass1234", result.getPasswordHash()); // Hasheado!
        assertTrue(result.getPasswordHash().startsWith("$2a$")); // BCrypt
        verify(cuentaDao).save(any(Cuenta.class));
    }

    @Test
    void crear_conEmailDuplicado_lanzaExcepcion() {
        AltaCuentaDto dto = new AltaCuentaDto(
            "Ana", "existente@mail.com", "12345678A",
            "ana", "Pass1234", "EXP-001", "Premium"
        );
        when(cuentaDao.existsByEmail("existente@mail.com")).thenReturn(true);

        DuplicateException ex = assertThrows(
            DuplicateException.class,
            () -> service.crear(dto)
        );
        assertEquals("El email ya está registrado", ex.getMessage());
        verify(cuentaDao, never()).save(any()); // No debe guardar
    }

    @Test
    void crear_conExpedienteInvalido_lanzaValidationError() {
        AltaCuentaDto dto = new AltaCuentaDto(
            "Ana", "ana@mail.com", "12345678A",
            "ana", "Pass1234", "", ""  // Expediente vacío
        );

        assertThrows(ValidationException.class,
            () -> service.crear(dto));
    }
}
Unit Test del Servlet — mockear Request/Response
// CuentaServletTest.java

@ExtendWith(MockitoExtension.class)
class CuentaServletTest {

    @Mock private CuentaService service;
    @Mock private HttpServletRequest request;
    @Mock private HttpServletResponse response;
    private CuentaServlet servlet;
    private StringWriter writer;

    @BeforeEach
    void setUp() throws Exception {
        servlet = new CuentaServlet(service);
        writer = new StringWriter();
        when(response.getWriter()).thenReturn(new PrintWriter(writer));
    }

    @Test
    void doPost_jsonValido_retorna201ConId() throws Exception {
        // GIVEN — simular body JSON en el request
        String json = """
            {"nombre":"Ana","email":"ana@mail.com","dni":"12345678A",
             "username":"ana","password":"Pass1234",
             "expediente":"EXP-001","tipoExpediente":"Premium"}
            """;
        when(request.getReader()).thenReturn(
            new BufferedReader(new StringReader(json)));

        Cuenta creada = new Cuenta();
        creada.setId(1L); creada.setUsername("ana");
        when(service.crear(any())).thenReturn(creada);

        // WHEN
        servlet.doPost(request, response);

        // THEN
        verify(response).setStatus(201);
        verify(response).setContentType("application/json");
        assertTrue(writer.toString().contains("\"id\":1"));
    }

    @Test
    void doPost_emailDuplicado_retorna409() throws Exception {
        String json = """
            {"nombre":"Ana","email":"dup@mail.com","dni":"12345678A",
             "username":"ana","password":"Pass1234",
             "expediente":"EXP-001","tipoExpediente":"Premium"}
            """;
        when(request.getReader()).thenReturn(
            new BufferedReader(new StringReader(json)));
        when(service.crear(any()))
            .thenThrow(new DuplicateException("Email ya registrado"));

        servlet.doPost(request, response);

        verify(response).setStatus(409);
        assertTrue(writer.toString().contains("Email ya registrado"));
    }
}
Test del DAO contra BD real (H2)
Objetivo: Verificar que las queries SQL y constraints (UNIQUE email, UNIQUE username) funcionan contra una BD real.
// CuentaDaoIntegrationTest.java — H2 in-memory

class CuentaDaoIntegrationTest {

    private static DataSource ds;
    private JdbcCuentaDao dao;

    @BeforeAll
    static void initDb() throws Exception {
        JdbcDataSource h2 = new JdbcDataSource();
        h2.setURL("jdbc:h2:mem:testdb;DB_CLOSE_DELAY=-1");
        ds = h2;
        // Crear tablas
        try (var conn = ds.getConnection();
             var stmt = conn.createStatement()) {
            stmt.execute("""
                CREATE TABLE cuentas (
                    id BIGINT AUTO_INCREMENT PRIMARY KEY,
                    nombre VARCHAR(100) NOT NULL,
                    email VARCHAR(150) NOT NULL UNIQUE,
                    dni VARCHAR(9) NOT NULL,
                    username VARCHAR(50) NOT NULL UNIQUE,
                    password_hash VARCHAR(200) NOT NULL,
                    expediente VARCHAR(20) NOT NULL,
                    tipo_expediente VARCHAR(30)
                )""");
        }
    }

    @BeforeEach
    void limpiar() { dao = new JdbcCuentaDao(ds); dao.deleteAll(); }

    @Test
    void save_yLuego_findByEmail_retornaMismo() {
        Cuenta c = crearCuentaTest("ana@mail.com", "ana");
        Cuenta guardada = dao.save(c);

        assertNotNull(guardada.getId());
        Cuenta encontrada = dao.findByEmail("ana@mail.com");
        assertEquals("ana", encontrada.getUsername());
    }

    @Test
    void save_emailDuplicado_lanzaSQLException() {
        dao.save(crearCuentaTest("dup@mail.com", "user1"));

        assertThrows(Exception.class, () ->
            dao.save(crearCuentaTest("dup@mail.com", "user2"))
        ); // UNIQUE constraint violation
    }

    @Test
    void existsByEmail_retornaTrueSiExiste() {
        dao.save(crearCuentaTest("existe@mail.com", "user1"));
        assertTrue(dao.existsByEmail("existe@mail.com"));
        assertFalse(dao.existsByEmail("noexiste@mail.com"));
    }

    private Cuenta crearCuentaTest(String email, String user) {
        return new Cuenta(null, "Test", email, "12345678A",
            user, "$2a$hash", "EXP-001", "Premium");
    }
}
Contrato del endpoint POST /api/cuentas
Request → Responses posibles
Request
POST /api/cuentas
Content-Type: application/json
{nombre, email, dni, username, password, expediente, tipoExpediente}
→
201 Created
{ id, username }
Cuenta creada OK
|
400 Bad Request
{ error, fields[] }
Validación fallida
|
409 Conflict
{ error, message }
Email/username duplicado
// CuentaApiContractTest.java — REST Assured

class CuentaApiContractTest {

    @Test
    void post_datosValidos_retorna201ConId() {
        given()
            .baseUri(BASE_URL)
            .contentType(ContentType.JSON)
            .body("""
                {"nombre":"Ana García","email":"nueva@mail.com",
                 "dni":"12345678A","username":"anagarcia",
                 "password":"Pass1234",
                 "expediente":"EXP-100","tipoExpediente":"Premium"}
                """)
        .when()
            .post("/api/cuentas")
        .then()
            .statusCode(201)
            .contentType(ContentType.JSON)
            .body("id", notNullValue())
            .body("username", equalTo("anagarcia"));
    }

    @Test
    void post_sinEmail_retorna400ConCamposInvalidos() {
        given()
            .baseUri(BASE_URL)
            .contentType(ContentType.JSON)
            .body("""
                {"nombre":"Ana","email":"","dni":"12345678A",
                 "username":"ana","password":"Pass1234",
                 "expediente":"EXP-100","tipoExpediente":"Premium"}
                """)
        .when()
            .post("/api/cuentas")
        .then()
            .statusCode(400)
            .body("error", equalTo("Validation failed"))
            .body("fields", hasItem("email"));
    }

    @Test
    void post_emailDuplicado_retorna409() {
        // Crear primero
        crearCuentaTest("dup@mail.com");

        // Intentar duplicar
        given()
            .baseUri(BASE_URL).contentType(ContentType.JSON)
            .body("""
                {"nombre":"Otro","email":"dup@mail.com","dni":"87654321B",
                 "username":"otro","password":"Pass1234",
                 "expediente":"EXP-200","tipoExpediente":"Basic"}
                """)
        .when()
            .post("/api/cuentas")
        .then()
            .statusCode(409)
            .body("message", containsString("ya está registrado"));
    }
}

// cuenta-validators.test.js — Vitest

import { describe, it, expect } from 'vitest';
import { validarEmail, validarPassword, validarDni, validarExpediente }
  from './cuenta-validators.js';

describe('validarEmail', () => {
  it('acepta emails válidos',  () => { expect(validarEmail('ana@mail.com')).toBe(true); });
  it('rechaza string vacío',   () => { expect(validarEmail('')).toBe(false); });
  it('rechaza sin arroba',     () => { expect(validarEmail('anamail.com')).toBe(false); });
  it('rechaza null',           () => { expect(validarEmail(null)).toBe(false); });
});

describe('validarPassword', () => {
  it('acepta ≥8 chars con número', () => { expect(validarPassword('Pass1234')).toBe(true); });
  it('rechaza < 8 chars',          () => { expect(validarPassword('Pa1')).toBe(false); });
  it('rechaza sin números',        () => { expect(validarPassword('Password')).toBe(false); });
});

describe('validarDni', () => {
  it('acepta 8 dígitos + letra', () => { expect(validarDni('12345678Z')).toBe(true); });
  it('rechaza sin letra',        () => { expect(validarDni('12345678')).toBe(false); });
  it('valida letra correcta',    () => { expect(validarDni('12345678A')).toBe(false); }); // letra real: Z
});

describe('validarExpediente', () => {
  it('acepta formato EXP-NNN', () => { expect(validarExpediente('EXP-001')).toBe(true); });
  it('rechaza vacío',           () => { expect(validarExpediente('')).toBe(false); });
});

// cuenta-api.test.js — Vitest + MSW

import { http, HttpResponse } from 'msw';
import { setupServer } from 'msw/node';
import { crearCuenta } from './cuenta-api.js';

const server = setupServer(
  http.post('/api/cuentas', async ({ request }) => {
    const body = await request.json();
    if (!body.email) return HttpResponse.json(
      { error: 'Validation failed', fields: ['email'] }, { status: 400 });
    return HttpResponse.json(
      { id: 1, username: body.username }, { status: 201 });
  })
);
beforeAll(() => server.listen());
afterAll(() => server.close());

describe('crearCuenta', () => {
  it('envía POST y retorna id', async () => {
    const res = await crearCuenta({
      nombre:'Ana', email:'ana@mail.com', dni:'12345678Z',
      username:'ana', password:'Pass1234',
      expediente:'EXP-001', tipoExpediente:'Premium'
    });
    expect(res.id).toBe(1);
    expect(res.username).toBe('ana');
  });

  it('lanza error si validación falla', async () => {
    await expect(crearCuenta({ email:'' })).rejects.toThrow('400');
  });
});

E2E con Cypress — alta de cuenta completa
Solo 3-5 tests E2E. Happy path + errores críticos. Todo lo demás ya lo cubren los unit e integration tests.
// cypress/e2e/alta-cuenta.cy.js

describe('Alta de cuenta', () => {
  beforeEach(() => {
    cy.request('POST', '/api/test/reset-db');
    cy.visit('/alta');
  });

  it('registra una cuenta nueva y redirige al login', () => {
    // Rellenar datos personales
    cy.get('[data-cy="nombre"]').type('Ana García');
    cy.get('[data-cy="email"]').type('ana@mail.com');
    cy.get('[data-cy="dni"]').type('12345678Z');

    // Rellenar cuenta
    cy.get('[data-cy="username"]').type('anagarcia');
    cy.get('[data-cy="password"]').type('Pass1234');
    cy.get('[data-cy="password-confirm"]').type('Pass1234');

    // Rellenar expediente
    cy.get('[data-cy="expediente"]').type('EXP-001');
    cy.get('[data-cy="tipo-expediente"]').select('Premium');

    // Submit
    cy.get('[data-cy="btn-crear"]').click();

    // Verificar resultado
    cy.url().should('include', '/login');
    cy.get('.toast-success').should('contain', 'Cuenta creada');
  });

  it('muestra error si email ya existe', () => {
    // Pre-crear cuenta vía API
    cy.request('POST', '/api/cuentas', {
      nombre:'Previo', email:'dup@mail.com', dni:'87654321B',
      username:'previo', password:'Pass1234',
      expediente:'EXP-099', tipoExpediente:'Basic'
    });

    // Intentar registrar con mismo email desde la UI
    cy.get('[data-cy="nombre"]').type('Otro');
    cy.get('[data-cy="email"]').type('dup@mail.com');
    cy.get('[data-cy="dni"]').type('11111111H');
    cy.get('[data-cy="username"]').type('otro');
    cy.get('[data-cy="password"]').type('Pass1234');
    cy.get('[data-cy="password-confirm"]').type('Pass1234');
    cy.get('[data-cy="expediente"]').type('EXP-100');
    cy.get('[data-cy="btn-crear"]').click();

    cy.get('.toast-error').should('contain', 'ya está registrado');
    cy.url().should('include', '/alta'); // No redirige
  });

  it('validación inline impide submit con campos vacíos', () => {
    cy.get('[data-cy="btn-crear"]').click();
    cy.get('.field-error').should('have.length.at.least', 3);
    cy.url().should('include', '/alta'); // No salió de la página
  });
});

Regla de decisión rápida
🎯
¿Dónde va este test?
1. ¿Es lógica pura sin BD ni red? → Unit con mock (JUnit+Mockito / Vitest)
2. ¿Toca BD real o SQL? → Integration con H2 (JUnit)
3. ¿Valida la forma del JSON o status codes? → Contract con REST Assured
4. ¿Es un flujo de usuario completo? → E2E con Cypress
5. ¿Ya lo cubre un nivel inferior? → NO lo dupliques
