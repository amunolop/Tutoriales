TU BRECHA REAL — DIAGNÓSTICO
⚠️ El 47.8% del examen es exactamente tu punto débil actual
Applications & Integration (33.1%) + Agents & Workflows (14.7%) exigen experiencia construyendo agentes con el Agent SDK / Claude API directamente. Tu experiencia hasta ahora es con Claude Code (orquestación desde CLI durante 3 meses) — muy valiosa, pero distinta de programar agentes desde cero contra la API. Ese es tu punto de partida real, no un detalle menor.
✅ Cómo cerrar la brecha con un solo recurso
El curso "Building with the Claude API" (9h, gratuito) cubre por sí solo prompting, tool use, RAG, agentes y patrones de producción — es decir, casi la mitad del examen. Es, con diferencia, tu mejor inversión de tiempo. Lo verás priorizado en la pestaña 🗓️ PLAN.

FASE 0 — FUNDAMENTOS PREVIOS (ANTES DEL EXAMEN)
Tu TFM (FMI) demuestra dominio de arquitectura y orquestación conceptual — el examen pide otra cosa: implementación directa contra la API. Antes de entrar en el plan de 8 semanas orientado al blueprint, conviene reconstruir la base desde cero, sin dar nada por sentado, para que lo técnico se apoye en algo sólido.
Fundamento 1Modelo mental

Claude 101 (2.5h) — sí, es el curso "no técnico". Da igual: te da el vocabulario base (mensajes, system prompt, contexto) sin asumir que ya lo conoces. Ve rápido por lo obvio, párate en lo nuevo.

Fundamento 2Cómo funciona un LLM

AI Capabilities and Limitations (3.5h) — predicción de siguiente token, qué es "conocimiento" para el modelo, memoria de trabajo, steerability, límites de contexto. Sin esto, el prompting y los agentes son recetas sueltas sin por qué.

Fundamento 3Delegar y evaluar

AI Fluency: Framework & Foundations (4h) — el framework 4D (Delegation, Description, Discernment, Diligence) que usa el propio Anthropic. Es la base mental para decidir qué delegar a un agente y cómo juzgar si su resultado es correcto.

Fundamento 4Primera llamada real

Antes del curso completo de la API: crea una API key en la Console, instala el SDK de Python o TypeScript, y haz tu primera llamada manual (client.messages.create()) sin seguir un curso — solo tú, la doc y el error que te salga.

PLAN DE 8 SEMANAS — YA CON LA BASE PUESTA
Diseñado en dos fases: primero la base conceptual (Fase 0), después el contenido específico del blueprint (semanas 1-8), donde las semanas 2-4 (Building with the Claude API) son las que más cuentan.
Semana 1Base

Claude Platform 101 completo + AI Capabilities and Limitations. Objetivo: entender el modelo mental de la plataforma antes de tocar código.

Semana 2Applications & Integration

Building with the Claude API — primer tercio (mensajes, prompting, streaming, manejo de errores). Practica cada bloque con tu propio código.

Semana 3Model Selection + Agents

Building with the Claude API — segundo tercio (tool use, elección de modelo, coste/latencia). Este es tu punto ciego: dedícale tiempo extra si hace falta.

Semana 4Agents & Workflows

Building with the Claude API — tercio final (agentes, RAG, patrones de producción) + blog "Building effective agents". Construye un agente mínimo con el Agent SDK.

Semana 5Agents & Workflows (práctica)

Blog "How we built our multi-agent research system" + "Effective context engineering". Replica un patrón manager/subagente a pequeña escala.

Semana 6Tools & MCPs

Introduction to MCP + MCP: Advanced Topics. Construye un servidor MCP simple con el SDK de Python.

Semana 7Prompt/Context + Security

Prompt Engineering Overview + Effective Context Engineering + repaso de la política de uso de Anthropic (Security & Safety).

Semana 8Repaso + Claude Code + registro

Claude Code 101 (repaso rápido) + Claude Cookbooks (evals) + repaso de la guía oficial del examen por dominio. Regístrate en el Partner Academy.

CÓMO REGISTRARTE (VÍA UST — PARTNER NETWORK)
El registro NO es público — requiere pertenecer a una organización del Claude Partner Network con email corporativo verificado. Como UST tiene acuerdo de partner con Anthropic, tu email @ust debería darte acceso directo.
Entra en el Anthropic Partner Academy con tu email corporativo de UST: anthropic-partners.skilljar.com
Busca la página del programa Claude Certification y localiza CCDV-F (Claude Certified Developer — Foundations).
Revisa la guía oficial del examen (Exam Guide v1.0) y los términos — cada página de certificación la incluye junto con los cursos de preparación.
Completa el registro y pago dentro del propio Partner Academy — el descuento de tu tier de partner se aplica automáticamente en el checkout.
Recibirás instrucciones para crear tu cuenta de Pearson VUE y agendar la sesión (online-proctorizada o en centro físico).
Día del examen: ID oficial vigente con el mismo nombre del registro, espacio de trabajo despejado — sin notas, móvil, smartwatch ni segunda pantalla.
⚠️ Si el Academy no reconoce tu email de UST
Comprueba que accedes con tu correo corporativo, no uno personal. Si el error persiste, escribe a partner-support@anthropic.com — vincular un dominio nuevo tarda 7-10 días, así que hazlo con margen antes de la fecha que quieras reservar.
