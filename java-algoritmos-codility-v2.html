Fórmula de Gauss
O(N) tiempo · O(1) espacio
Fácil

La suma de los primeros N números naturales siempre es (N+1)×N/2. Si conoces lo que debería sumar una secuencia continua, puedes detectar cualquier anomalía comparando con la suma real.

💡 Intuición clave
Suma esperada − Suma real = elemento faltante (o duplicado). Es como saber que una caja tiene 10 naranjas: si pesas la caja y pesa menos, falta una naranja.

Úsalo cuando: el array debería contener una secuencia continua de números y falta o sobra alguno.

⚖️
Índice de Equilibrio
O(N) tiempo · O(1) espacio
Fácil

Buscar la posición donde la suma de los elementos a la izquierda iguala la suma de los elementos a la derecha. La clave es usar la suma total para evitar recalcular en cada paso.

💡 Intuición clave
sumaDer = sumaTotal − sumaIzq − A[i]. No necesitas recorrer el array dos veces. Es como una balanza: si sabes el peso total y lo que hay a la izquierda, calculas la derecha al instante.

Úsalo cuando: busques un punto de balance, pivote o partición en un array.

🔢
Permutación
O(N) tiempo · O(N) espacio
Fácil

Verificar que un array contiene exactamente los números 1, 2, 3... N sin repeticiones ni huecos. Requiere dos condiciones juntas: la suma de Gauss correcta Y sin duplicados.

⚠️ Trampa clásica
Solo con Gauss no basta. El array [1,1,4] suma igual que [1,2,3] pero no es permutación. Necesitas también comprobar que no hay repetidos con un HashSet.

Úsalo cuando: debas validar que un array es una reordenación exacta de 1..N.

🔍
Búsqueda Binaria
O(log N) tiempo · O(1) espacio
Medio

Buscar un elemento en un array ordenado dividiendo el espacio de búsqueda a la mitad en cada paso. Requiere que el array esté ordenado.

💡 Intuición clave
Es como buscar una palabra en un diccionario: abres por el medio, ves si tu palabra va antes o después, y descartas la mitad. En 20 pasos puedes buscar entre un millón de elementos.

Úsalo cuando: el array esté ordenado y necesites localizar un elemento o un umbral.

👉
Two Pointers
O(N) tiempo · O(1) espacio
Medio

Dos índices que avanzan desde los extremos (o desde el mismo punto) hacia el centro. Elimina la necesidad de bucles anidados O(N²) en muchos problemas de pares.

💡 Intuición clave
Si la suma de los extremos es demasiado grande, mueve el puntero derecho hacia dentro. Si es demasiado pequeña, mueve el izquierdo. Como ajustar una balanza por los dos extremos a la vez.

Úsalo cuando: busques pares, palíndromos, o debas invertir/comparar desde los extremos.

🪟
Sliding Window
O(N) tiempo · O(1) espacio
Medio

Una ventana de tamaño fijo (o variable) desliza por el array. En cada paso suma el nuevo elemento y resta el que sale, evitando recalcular toda la ventana.

💡 Intuición clave
Es como una ventana de tren: al avanzar entra un árbol nuevo y sale el anterior. No necesitas contar todos los árboles visibles cada vez, solo sumar uno y restar otro.

Úsalo cuando: trabajes con subarrays de tamaño fijo: máximos, mínimos, medias móviles.

➕
Prefix Sum
O(N) preproceso · O(1) consulta
Medio

Precalcular las sumas acumuladas del array. Permite responder cualquier consulta de suma de subarray en O(1) con la fórmula prefix[r+1] − prefix[l].

💡 Intuición clave
Es como los marcadores de kilómetros en una autopista: para saber la distancia entre el km 30 y el km 80, no recorres el trayecto, simplemente restas 80 − 30 = 50 km.

Úsalo cuando: necesites responder múltiples consultas de suma sobre rangos del array.

Ejercicio 1 — Elemento faltante Fácil O(N) · O(1)
Array de N enteros distintos con todos los números del 1 al N+1 excepto uno. Encontrar el número que falta.
Intenta resolverlo primero
Solución
public int solution(int[] A) {
    int  n        = A.length;
    long esperada = (long)(n+2) * (n+1) / 2;
    long real     = 0;
    for (int x : A) real += x;
    return (int)(esperada - real);
}
Traza — A = [2, 3, 1, 5]
n        = 4
esperada = (6×5)/2 = 15
real     = 2+3+1+5 = 11

resultado = 15 - 11 = 4 ✓

Ejercicio 2 — Elemento duplicado Fácil O(N) · O(1)
Array de N+1 enteros donde todos están en el rango 1..N. Exactamente uno se repite. Encontrar el duplicado. La lógica es inversa: la suma real es mayor que la esperada.
Intenta resolverlo primero
Solución
public int solution(int[] A) {
    int  n        = A.length - 1;
    long esperada = (long)n * (n+1) / 2;
    long real     = 0;
    for (int x : A) real += x;
    return (int)(real - esperada);
    // ahora real - esperada = duplicado
}
Traza — A = [1, 3, 2, 3, 4]
n        = 4
esperada = (4×5)/2 = 10
real     = 1+3+2+3+4 = 13

resultado = 13 - 10 = 3 ✓
Índice de Equilibrio — balance de sumas
Ejercicio 1 — Primer índice de equilibrio Fácil O(N) · O(1)
Encontrar el índice i donde la suma de A[0..i-1] == suma de A[i+1..N-1]. El elemento A[i] no cuenta en ninguna de las dos partes.
Intenta resolverlo primero
Solución
public int solution(int[] A) {
    int n = A.length;

    // Paso 1: suma total
    long total = 0;
    for (int x : A) total += x;

    // Paso 2: buscar equilibrio
    long izq = 0;
    for (int i = 0; i < n; i++) {
        long der = total - izq - A[i];
        if (izq == der) return i;
        izq += A[i];
    }
    return -1;
}
Traza — A = [-1, 3, -4, 5, 1, -6, 2, 1]
total = 1

i=0: izq=0  der=1-0-(-1)=2  ❌
i=1: izq=-1 der=1-(-1)-3=-1 ✓

retorna i = 1

Ejercicio 2 — Todos los índices de equilibrio Fácil O(N) · O(N)
Variante: devolver todos los índices de equilibrio que existan en el array, no solo el primero.
Intenta resolverlo primero
Solución
public int[] solution(int[] A) {
    int n = A.length;
    long total = 0;
    for (int x : A) total += x;

    long izq = 0;
    ArrayList<Integer> res = new ArrayList<>();
    for (int i = 0; i < n; i++) {
        long der = total - izq - A[i];
        if (izq == der) res.add(i);
        izq += A[i];
    }
    return res.stream().mapToInt(Integer::intValue).toArray();
}
Ejemplo — A = [-1, 3, -4, 5, 1, -6, 2, 1]
Índices de equilibrio: 1, 3, 7

i=1: izq=-1  der=-1  ✓
i=3: izq=-2  der=-2  ✓
i=7: izq=0   der=0   ✓
Permutación — verificar secuencia completa 1..N
Ejercicio 1 — ¿Es permutación? Fácil O(N) · O(N)
Dado un array de N enteros, devolver 1 si contiene exactamente los números 1, 2, 3... N sin repeticiones, o 0 si no.
Intenta resolverlo primero
Solución — Gauss + HashSet
public int solution(int[] A) {
    int  n        = A.length;
    long esperada = (long)n * (n+1) / 2;
    long real     = 0;
    for (int x : A) real += x;
    if (real != esperada) return 0;

    // Sin duplicados
    HashSet<Integer> vistos = new HashSet<>();
    for (int x : A)
        if (!vistos.add(x)) return 0;
    return 1;
}
Casos de prueba
ArrayGauss ✓Sin dupl.Res.
[4,1,3,2]10==10✅1
[1,1,4]6==6❌ 1 rep.0
[1,2,5]8≠6—0
[1]1==1✅1
⚠️ Por qué necesitas las dos condiciones
[1,1,4] pasa Gauss (suma=6) pero tiene duplicado. [1,2,5] falla Gauss directamente. Solo juntas son condición necesaria y suficiente.
Ejercicio 2 — Primer elemento que falta (1..N+1) Fácil O(N) · O(N)
Dado un array de enteros positivos distintos, encontrar el entero positivo más pequeño que no aparece en el array.
Intenta resolverlo primero
Solución
public int solution(int[] A) {
    HashSet<Integer> set = new HashSet<>();
    for (int x : A) set.add(x);

    for (int i = 1; i <= A.length + 1; i++)
        if (!set.contains(i)) return i;

    return A.length + 1;
}

Búsqueda Binaria — divide y vencerás
Ejercicio 1 — Buscar elemento Medio O(log N) · O(1)
Dado un array ordenado y un valor target, devolver su índice o -1 si no existe.
Intenta resolverlo primero
Solución
public int buscar(int[] A, int target) {
    int izq = 0, der = A.length - 1;
    while (izq <= der) {
        int mid = izq + (der - izq) / 2;
        if      (A[mid] == target) return mid;
        else if (A[mid] <  target) izq = mid + 1;
        else                         der = mid - 1;
    }
    return -1;
}
Traza — A=[1,3,5,7,9], target=7
paso 1: mid=2 A[2]=5  < 7 → izq=3
paso 2: mid=4 A[4]=9  > 7 → der=3
paso 3: mid=3 A[3]=7 == 7 ✓

retorna índice 3
💡 Por qué mid = izq + (der - izq) / 2
Si usas (izq + der) / 2 puede haber overflow cuando izq y der son números grandes. La fórmula izq + (der - izq) / 2 es equivalente pero segura.
Ejercicio 2 — Buscar primer elemento ≥ target Medio O(log N) · O(1)
Variante muy común: encontrar el índice del primer elemento mayor o igual que el target (lower bound).
Intenta resolverlo primero
Solución
public int lowerBound(int[] A, int target) {
    int izq = 0, der = A.length;
    while (izq < der) {
        int mid = izq + (der - izq) / 2;
        if (A[mid] < target)
            izq = mid + 1;
        else
            der = mid;
    }
    return izq; // índice del primero >= target
}

Ejercicio 1 — Par con suma objetivo Medio O(N log N) · O(1)
Dado un array y un valor K, determinar si existe algún par de elementos cuya suma sea exactamente K. El array debe estar ordenado (o se ordena primero).
Intenta resolverlo primero
Solución
public boolean parConSuma(int[] A, int K) {
    Arrays.sort(A);
    int izq = 0, der = A.length - 1;
    while (izq < der) {
        int suma = A[izq] + A[der];
        if      (suma == K) return true;
        else if (suma <  K) izq++;
        else               der--;
    }
    return false;
}
Traza — A=[1,3,5,7,9], K=10
A ordenado: [1,3,5,7,9]

izq=0 der=4: 1+9=10 ✓

retorna true

// Si K=6:
izq=0 der=4: 1+9=10 > 6 → der--
izq=0 der=3: 1+7=8  > 6 → der--
izq=0 der=2: 1+5=6  == 6 ✓
Ejercicio 2 — Invertir array Fácil O(N) · O(1)
Invertir un array in-place sin crear uno nuevo. Los punteros avanzan desde los extremos hacia el centro intercambiando elementos.
Intenta resolverlo primero
Solución
public void invertir(int[] A) {
    int izq = 0, der = A.length - 1;
    while (izq < der) {
        int tmp  = A[izq];
        A[izq]  = A[der];
        A[der]  = tmp;
        izq++; der--;
    }
}
Traza — A = [1, 2, 3, 4, 5]
paso 1: swap(1,5) → [5,2,3,4,1]
paso 2: swap(2,4) → [5,4,3,2,1]
paso 3: izq==der (centro)

resultado: [5,4,3,2,1] ✓
Sliding Window — ventana deslizante de tamaño K
Ejercicio 1 — Suma máxima de K elementos consecutivos Medio O(N) · O(1)
Dado un array y un entero K, encontrar la suma máxima de cualquier subarray de exactamente K elementos consecutivos.
Intenta resolverlo primero
Solución
public int sumaMaxima(int[] A, int K) {
    int n = A.length;
    int suma = 0;

    // Primera ventana
    for (int i = 0; i < K; i++)
        suma += A[i];
    int max = suma;

    // Deslizar: entra A[i], sale A[i-K]
    for (int i = K; i < n; i++) {
        suma += A[i] - A[i - K];
        max  = Math.max(max, suma);
    }
    return max;
}
Traza — A=[2,1,5,1,3,2], K=3
ventana 1: [2,1,5] suma=8  max=8
ventana 2: [1,5,1] suma=7  max=8
ventana 3: [5,1,3] suma=9  max=9
ventana 4: [1,3,2] suma=6  max=9

resultado: 9 ✓
Ejercicio 2 — Media móvil Fácil O(N) · O(N)
Calcular la media de cada ventana de K elementos consecutivos. Muy útil en señales (¡teleco! 📡).
Intenta resolverlo primero
Solución
public double[] mediaMovil(int[] A, int K) {
    int      n   = A.length;
    double[] res = new double[n - K + 1];
    int      suma = 0;

    for (int i = 0; i < K; i++)
        suma += A[i];
    res[0] = (double) suma / K;

    for (int i = K; i < n; i++) {
        suma       += A[i] - A[i - K];
        res[i-K+1] = (double) suma / K;
    }
    return res;
}
Ejemplo — A=[4,2,6,8,3], K=3
ventana 1: (4+2+6)/3 = 4.0
ventana 2: (2+6+8)/3 = 5.33
ventana 3: (6+8+3)/3 = 5.67

resultado: [4.0, 5.33, 5.67]

Prefix Sum — sumas acumuladas para consultas O(1)
Ejercicio 1 — Suma de rango Medio O(N) preproceso · O(1) consulta
Dado un array, responder múltiples consultas de la forma "¿cuánto suma A[l..r]?" en O(1) cada una después de un preprocesado O(N).
Intenta resolverlo primero
Solución
// Construir array de prefijos
int[] buildPrefix(int[] A) {
    int[] p = new int[A.length + 1];
    for (int i = 0; i < A.length; i++)
        p[i+1] = p[i] + A[i];
    return p;
}

// Consulta: suma A[l..r] en O(1)
int query(int[] p, int l, int r) {
    return p[r+1] - p[l];
}
Traza — A = [1, 2, 3, 4, 5]
A:      [1,  2,  3,  4,  5]
prefix: [0,  1,  3,  6, 10, 15]

suma A[1..3]:
= prefix[4] - prefix[1]
= 10 - 1 = 9 ✓ (2+3+4)

suma A[0..4]:
= prefix[5] - prefix[0]
= 15 - 0 = 15 ✓
Ejercicio 2 — Subarray con suma cero Medio O(N) · O(N)
Determinar si existe algún subarray cuya suma sea exactamente cero. Si dos prefijos son iguales, el subarray entre ellos suma cero.
Intenta resolverlo primero
Solución
public boolean haySubarrayCero(int[] A) {
    HashSet<Long> vistos = new HashSet<>();
    vistos.add(0L); // prefijo vacío
    long suma = 0;
    for (int x : A) {
        suma += x;
        // si este prefijo ya apareció → subarray cero
        if (!vistos.add(suma)) return true;
    }
    return false;
}
Traza — A = [3, 1, -4, 2, -2]
prefijos acumulados:
0 → 3 → 4 → 0 ← ¡repetido!

0 ya estaba en el set → true ✓

subarray: A[0..2] = [3,1,-4] suma=0
💡 Por qué funciona
Si prefix[i] == prefix[j] siendo i < j, entonces la suma del subarray A[i..j-1] es cero. Es la misma lógica que el equilibrio pero aplicada a prefijos repetidos.
