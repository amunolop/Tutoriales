01 — Conceptos fundamentales

¿Qué es cada cosa?

Cada término describe una capa diferente de la tecnología. Entenderlos evita confusiones.

🧠
La base de todo

LLM — Large Language Model

Un modelo de red neuronal entrenado con cantidades masivas de texto. Es el «cerebro» crudo: recibe texto y predice qué viene después. No tiene interfaz, no habla contigo — es solo matemáticas y pesos neuronales. Todo lo demás se construye encima.

GPT-4o Claude Opus Llama 3 Gemini Pro Mistral Large
👨‍👩‍👧‍👦
Versiones y variantes

Familia de modelos

Un conjunto de modelos relacionados que comparten arquitectura pero varían en tamaño, coste y capacidad. Cada empresa lanza una «familia» con versiones pequeñas (baratas y rápidas), medianas y grandes (potentes y caras). Como una gama de coches: mismo fabricante, diferente potencia.

GPT-4 → 4o, 4o-mini Claude → Haiku, Sonnet, Opus Llama → 8B, 70B, 405B
💬
Interfaz conversacional

Chatbot

Una interfaz que te permite hablar con un LLM como si fuera una persona. Añade la capa de conversación: mantiene contexto, sigue instrucciones y da respuestas legibles. Es el «envoltorio» amigable alrededor del modelo.

ChatGPT Claude.ai Gemini Copilot
🤖
Automatización simple

Bot

Un programa que ejecuta tareas automáticas siguiendo reglas predefinidas. No necesita IA: un bot de Telegram que reenvía mensajes o un bot de Discord que modera son bots «clásicos». Sigue scripts fijos, no «piensa».

Bot de Telegram Bot de Discord Web scraper Bot de trading
⚡
IA con autonomía

Agente de IA

Un sistema que usa un LLM para razonar, planificar y ejecutar tareas de forma autónoma. Un chatbot responde lo que le preguntas; un agente decide qué hacer, usa herramientas (buscar en web, ejecutar código, llamar APIs) y completa objetivos complejos por su cuenta.

Claude Code Devin AutoGPT Operator Manus
🔌
Acceso programático

API de LLM

La puerta de entrada para desarrolladores. En vez de chatear en una web, envías peticiones HTTP y recibes respuestas del modelo. Pagas por uso (tokens consumidos) y tienes control total sobre el comportamiento.

OpenAI API Anthropic API Google AI Studio Together AI

03 — Familias de modelos

Los grandes jugadores del mercado

Cada empresa tiene su propia familia de modelos con variantes para distintos usos y presupuestos.

OpenAI — GPT

OpenAI · San Francisco

La familia que popularizó los LLMs. GPT-4o es su modelo insignia multimodal (texto, imagen, audio). La serie «o» (o1, o3, o4-mini) añade razonamiento profundo paso a paso. GPT-4o-mini es la versión económica.

GPT-4o o3 o4-mini GPT-4o mini GPT-4.1 DALL·E 3 Whisper Sora

Anthropic — Claude

Anthropic · San Francisco

Enfocada en seguridad y fiabilidad. Claude destaca en razonamiento largo, escritura, código y seguir instrucciones complejas. Tres niveles: Haiku (rápido/barato), Sonnet (equilibrado) y Opus (máxima capacidad).

Claude Opus 4.5 Claude Sonnet 4.5 Claude Haiku 4.5 Claude Code

Google — Gemini

Google DeepMind · Mountain View

Nativamente multimodal (texto, imagen, audio, vídeo, código). Gemini 2.5 Pro destaca por su ventana de contexto enorme (1M+ tokens). Flash es la versión rápida y económica.

Gemini 2.5 Pro Gemini 2.0 Flash Gemini 1.5 Pro Gemma 2 (open) Imagen 3

Meta — Llama

Meta AI · Menlo Park

La gran familia open-source. Puedes descargar y ejecutar los modelos en tu propio hardware. Disponible en varios tamaños. Base de muchísimos proyectos de código abierto.

Llama 4 Maverick Llama 4 Scout Llama 3.3 70B Llama 3.1 405B Llama 3.1 8B Code Llama

Mistral AI

Mistral · París

Startup francesa con modelos open-source de alto rendimiento. Arquitectura MoE (Mixture of Experts) permite modelos muy eficientes. Mistral Large compite con los grandes.

Mistral Large Mistral Medium Mistral Small Mixtral 8x22B Codestral Pixtral

DeepSeek

DeepSeek · Hangzhou, China

Laboratorio chino que sorprendió con modelos de razonamiento open-source de nivel frontier. DeepSeek-R1 compite con o1 en razonamiento matemático. Usa MoE y destaca por eficiencia.

DeepSeek-R1 DeepSeek-V3 DeepSeek Coder V2
04 — Herramientas y plataformas

Dónde y cómo usas la IA

Más allá de los modelos, hay un ecosistema de herramientas para ejecutar, conectar y aprovechar la IA.

Ollama

Ejecución local de modelos

Software que te permite descargar y ejecutar LLMs open-source en tu propio ordenador. Sin internet, sin pagar API, todo privado. Soporta Llama, Mistral, Gemma, DeepSeek y más.

ChatboxtAI

Cliente de escritorio multi-modelo

Aplicación de escritorio como interfaz universal para múltiples LLMs. Conecta APIs de OpenAI, Anthropic, o modelos locales vía Ollama. Un solo lugar para todos tus modelos.

LM Studio

Ejecución local con interfaz gráfica

Similar a Ollama pero con interfaz visual completa. Descarga modelos de Hugging Face, chatea con ellos y ajusta parámetros. Ideal si prefieres no usar la terminal.

Hugging Face

Hub de modelos y datasets

El «GitHub de la IA». Repositorio donde se publican modelos, datasets y demos. Centro neurálgico de la comunidad open-source de Machine Learning.

LangChain / LlamaIndex

Frameworks para desarrollo

Frameworks de Python/JS para construir aplicaciones con LLMs. Encadenar llamadas, conectar bases de datos, hacer RAG, crear agentes. Las herramientas de los desarrolladores.

OpenRouter / Together AI

API gateway multi-modelo

Acceso a decenas de modelos con una sola API key. En vez de tener cuenta en cada proveedor, usas una interfaz para GPT-4, Claude, Llama, Mistral, etc.
