Arquitectura de Procesamiento con SkipLimit Dinámico (%)

⚙️ 1. Propiedades de Negocio (application.properties)

# Definimos el margen de error permitido (del 1% al 5%)
batch.error.threshold.percentage=1.0
batch.error.max.allowed.percentage=5.0

🧮 2. Cálculo Dinámico del Umbral

Este componente cuenta las líneas del archivo y calcula cuántos registros se pueden saltar antes de fallar el Job.

@Value("${batch.error.threshold.percentage:1.0}")
private double threshold;

@Override
public RepeatStatus execute(...) {
  long lines = Files.lines(path).count();
  long skipLimit = (long) Math.ceil(lines * (threshold / 100.0));
  // Guardamos en el contexto del Job para el siguiente Step
  jobExecutionContext.put("computedSkipLimit", skipLimit);
  return RepeatStatus.FINISHED;
}

🏗️ 3. Step con Late Binding

@Bean
@StepScope
public Step mainStep(
  @Value("#{jobExecutionContext['computedSkipLimit']}") Integer limit) {
  return new StepBuilder("step", repository)
    .chunk(50, tm)
    .faultTolerant()
    .skip(Exception.class).skipLimit(limit)
    .listener(auditListener)
    .build();
}
