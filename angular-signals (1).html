Angular 16+

Entendiendo Signals

Reactividad granular sin RxJS. Más simple, más rápido, más predecible.

1 CONCEPTO

¿Qué es un Signal?

Un Signal es un contenedor reactivo de valor. Cuando su valor cambia, Angular sabe exactamente qué partes de la UI actualizar — sin Zone.js, sin detectar todo el árbol.

📡

signal()

Crea un valor reactivo que puedes leer y escribir. Es la unidad fundamental.

⚙️

computed()

Deriva un valor de otros signals. Se recalcula automáticamente cuando cambian sus dependencias.

⚡

effect()

Ejecuta código como efecto secundario cada vez que un signal cambia. Ideal para logs, peticiones HTTP, etc.

🎯

Granular

Solo se actualizan los componentes afectados. No más change detection global.

2 FLUJO

Cómo se conectan

Los signals forman un grafo de dependencias reactivo, donde los datos fluyen de forma unidireccional.

signal()fuente de datos
→
computed()derivado
→
effect()efecto secundario
3 SIGNAL

Crear y mutar un Signal

Usa signal() para crear, .set() para reemplazar, .update() para transformar.

counter.component.ts 
import { Component, signal } from '@angular/core';

@Component({
  selector: 'app-counter',
  standalone: true,
  template: `
    <h2>Contador: {{ count() }}</h2>
    <button (click)="increment()">+1</button>
    <button (click)="reset()">Reset</button>
  `
})
export class CounterComponent {

  // Crear un signal con valor inicial 0
  count = signal(0);

  increment() {
    // .update() recibe el valor actual
    this.count.update(v => v + 1);
  }

  reset() {
    // .set() reemplaza el valor directamente
    this.count.set(0);
  }
}
4 COMPUTED

Valores derivados con computed()

Un computed() es de solo lectura y se recalcula automáticamente cuando sus dependencias cambian.

cart.component.ts 
import { Component, signal, computed } from '@angular/core';

@Component({
  selector: 'app-cart',
  standalone: true,
  template: `
    <p>Precio: {{ price() }}€</p>
    <p>Cantidad: {{ quantity() }}</p>
    <p><strong>Total: {{ total() }}€</strong></p>

    <button (click)="addItem()">+1 unidad</button>
    <button (click)="removeItem()">-1 unidad</button>
    <button (click)="applyDiscount()">Aplicar 20% dto</button>
  `
})
export class CartComponent {

  price    = signal(29.99);
  quantity = signal(2);

  // ⚙️ Se recalcula AUTOMÁTICAMENTE cuando price o quantity cambian
  // No necesitas suscribirte ni llamarlo manualmente
  total = computed(() =>
    Math.round(this.price() * this.quantity() * 100) / 100
  );

  // Al cambiar quantity → total() se recalcula
  addItem() {
    this.quantity.update(q => q + 1);
  }

  removeItem() {
    this.quantity.update(q => Math.max(0, q - 1));
  }

  // Al cambiar price → total() también se recalcula
  applyDiscount() {
    this.price.update(p =>
      Math.round(p * 0.8 * 100) / 100
    );
  }
}
5 EFFECT

Efectos secundarios con effect()

Los effects se ejecutan automáticamente cuando las signals que leen cambian. Perfecto para sincronizar con APIs externas.

search-logger.component.ts 
import { Component, signal, computed, effect } from '@angular/core';
import { AnalyticsService } from './analytics.service';

@Component({ ... })
export class SearchComponent {

  // Signals (datos)
  query    = signal('');
  category = signal('todos');

  // Computed (derivado)
  searchUrl = computed(() =>
    `/api/search?q=${this.query()}&cat=${this.category()}`
  );

  constructor(private analytics: AnalyticsService) {

    // ⚡ EFFECT: se ejecuta SOLO cuando query o category cambian
    // Angular detecta automáticamente qué signals lee
    effect(() => {
      const q   = this.query();
      const cat = this.category();

      // Efecto secundario 1: guardar en localStorage
      localStorage.setItem('lastSearch', JSON.stringify({ q, cat }));

      // Efecto secundario 2: enviar analytics
      this.analytics.track('search', { q, cat });

      // Efecto secundario 3: log en consola
      console.log(`🔍 Buscando "${q}" en ${cat}`);
    });
  }
}
🔑

La diferencia clave

signal() almacena datos. effect() no devuelve nada — solo ejecuta acciones externas (localStorage, HTTP, logs, DOM) cuando los signals que lee cambian.

🚫

No confundir con computed

computed() calcula un valor derivado. effect() produce efectos secundarios. Nunca uses effect() para derivar valores.
