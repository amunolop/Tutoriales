Motor de Migración Universal

Herramienta de línea de comandos que transforma ficheros CSV en sentencias SQL INSERT listas para cargar en base de datos. Disponible en dos implementaciones idénticas: Python 3.10+ y Node.js 18+, ambas sin dependencias externas. El motor valida cada campo del CSV antes de generar el SQL, gestiona NULLs automáticamente y es capaz de reparar registros con separadores embebidos dentro de comillas dobles sin modificar el fichero original.

Cómo ejecutar

migracion.py Python

Requiere Python 3.10 o superior. Sin instalación de paquetes.

python migracion.py
migracionNodeJs.txt Node.js

Requiere Node.js 18+. Renombrar a .js antes de ejecutar.

node migracionNodeJs.js

Ficheros del proyecto

El motor trabaja con tres ficheros de entrada que preparas tú, genera dos ficheros de salida y mantiene un log de sesión. Haz clic en el nombre de cualquier fichero para verlo.

Fichero Tipo Para qué sirve
GCV_FINCAS.csv Entrada El CSV con los datos a migrar. Separador ;, con cabecera, 18 columnas. Los campos vacíos o con el literal null se tratarán como NULL SQL según la configuración. Los campos que contengan el separador deben ir entre comillas dobles: "CALLE MAYOR; 1". El encoding es configurable al cargarlo (opción 1): acepta utf-8, ansi, cp1252, iso-8859-1, etc.
config_gcv_fincas.json Config Define las reglas de validación columna a columna. Campos clave:
  • "separador" — carácter separador del CSV (normalmente ";")
  • "nombre" — identificador de la columna; debe coincidir exactamente con el {PLACEHOLDER} de la plantilla SQL
  • "regex" — expresión regular que debe cumplir el valor (se aplica fullmatch, es decir, debe cubrir el valor completo)
  • "nullable": true — si el campo está vacío o es null, se convierte en SQL NULL en lugar de rechazar el registro
  • "nullable": false — si el campo está vacío, el registro va a KO con el motivo indicado
insert_gcv_fincas.txt Plantilla Una sola línea con la sentencia INSERT completa. Los {NOMBRE} son los placeholders que el motor sustituirá con los valores del CSV. Los nombres deben coincidir exactamente con los "nombre" del JSON. Los campos nullable se escriben entre comillas simples en la plantilla ('{ID_UNICO}'); el motor reemplaza el valor centinela por NULL sin comillas cuando corresponde. Admite funciones SQL como TO_TIMESTAMP('{FECHA_ALTA}', 'YYYY-MM-DD HH24:MI:SS.FF1').
migracion_final.sql Salida Uno o varios ficheros SQL generados por el motor (opción 5). Cada fichero incluye una cabecera de comentarios con fecha de generación, total de registros, número de fichero y modo de transacción. Si se configura un límite de sentencias por fichero, se generan secuencialmente: migracion_final_001.sql, migracion_final_002.sql… La anchura del sufijo numérico se adapta automáticamente al número total de ficheros.
errores_KO.csv Errores Generado automáticamente al terminar la validación si hay registros rechazados. Contiene las mismas columnas del CSV original más dos extras al final: N_LINEA (número de línea en el fichero original para localizar el error rápidamente) y ERROR_CAUSA (motivo exacto del rechazo: campo no nullable, regex no cumplida, número de columnas incorrecto…). El nombre incluye timestamp para no sobrescribir pasadas anteriores. No es necesario releer este fichero: la opción 4 trabaja directamente con los KO que están en memoria.
migracion_*.log Log Fichero de log generado automáticamente en la misma carpeta donde se ejecuta el programa. Incluye todos los eventos de la sesión: cargas de ficheros, errores de validación con número de línea, reparaciones OK, advertencias de claves faltantes en plantilla y ruta de cada fichero SQL generado. El nombre incluye timestamp de inicio de sesión.

Fases del proceso

El motor sigue un flujo en cinco fases que se ejecutan a través del menú interactivo. Las fases 1 y 2 son de preparación; las fases 3 y 4 son iterativas (se pueden repetir hasta que no queden KO); la fase 5 es la generación final.

FASE 1
Ingesta del CSV [Opción 1]

El programa lee el fichero CSV línea a línea y almacena las líneas de datos en memoria (sin la cabecera si la tiene). Se puede ejecutar varias veces para acumular registros de distintos ficheros: cada carga añade líneas al buffer existente sin borrar las anteriores, permitiendo consolidar múltiples CSV antes de validar.

El motor pregunta: ruta del fichero, si tiene cabecera (para saltársela), y encoding. Los alias de encoding habituales se normalizan automáticamente: escribir ansi equivale a cp1252 (Python) / latin1 (Node.js), que es el encoding que Notepad++ llama "ANSI".

Estado en memoria tras esta fase: N líneas pendientes de validar
FASE 2
Carga de la configuración JSON [Opción 2]

El motor lee el fichero JSON que define las reglas de validación: separador del CSV, nombre de cada columna, su expresión regular y si admite valores nulos. Tras la carga, compila todas las regex en un caché interno para que no se recompilen en cada línea del CSV — fundamental para rendimiento con cientos de miles de registros.

Solo es necesario cargar la configuración una vez por sesión. Si se carga una segunda vez, la anterior se reemplaza y el caché se invalida.

Estado en memoria tras esta fase: config cargada + regex compiladas
FASE 3
Validación [Opción 3]

El motor recorre todas las líneas en memoria y valida cada una. Al iniciar, pregunta el modo:

  • Modo completo — verifica el número de campos, aplica las regex de cada columna y comprueba los nullable. Es el modo definitivo para generar el SQL.
  • Modo solo campos — únicamente verifica que cada línea tenga el número correcto de columnas. Los valores pasan tal cual sin validar su formato. Útil para un primer sondeo rápido del fichero o cuando el CSV tiene campos con formatos irregulares que se quieren aceptar sin restricción.

Para cada línea KO, el motor imprime inmediatamente en consola el número de línea y el motivo del error, y lo registra en el log. Al terminar exporta un CSV de errores con N_LINEA y ERROR_CAUSA.

Las líneas OK pasan a lineas_ok. Las KO se guardan en lineas_ko para la siguiente fase. El buffer de pendientes queda vacío.

Estado en memoria tras esta fase: lineas_ok + lineas_ko + modo guardado
FASE 4
Reparar KO — split con comillas [Opción 4]

Diseñada para resolver el caso más frecuente de error en ficheros reales: campos que contienen el separador (;) dentro de comillas dobles. Por ejemplo, un campo dirección como "ESCRITORA EMILIA PARDO BAZAR S/N;8507;63" con un split simple de ; se parte en tres fragmentos y la línea parece tener más columnas de las esperadas.

La opción 4 toma las líneas KO que están en memoria (no hace falta releer ningún fichero) y las re-parsea con un algoritmo consciente de comillas: recorre carácter a carácter y solo considera separador los ; que están fuera de un bloque entre comillas dobles. Las comillas dobles internas representadas como "" se normalizan a ".

Los campos ya partidos correctamente se pasan directamente al validador sin reconstruir la línea (para que los ; internos no vuelvan a romper el split). El modo usado (completo / solo campos) se hereda automáticamente de la opción 3.

Las líneas que ahora validan pasan a lineas_ok; las que siguen fallando permanecen en lineas_ko y se exportan a un nuevo CSV de errores.

Estado en memoria tras esta fase: lineas_ok aumentado · lineas_ko reducido (o vacío)
FASE 5
Generación de SQL [Opción 5]

El motor toma todos los registros validados (lineas_ok), aplica la plantilla SQL a cada uno sustituyendo los {PLACEHOLDER} por los valores del registro, y escribe los ficheros de salida. Antes de escribir convierte el centinela NULL (valor interno) en la palabra NULL sin comillas, tanto si aparecía entrecomillado en la plantilla ('{ID_UNICO}') como si no.

Pregunta tres cosas:

  • Nombre base del fichero de salida (ej: migracion_final.sql)
  • Tamaño de batch — cada cuántas sentencias insertar un COMMIT. Con 0 no se generan transacciones.
  • Máximo de sentencias por fichero — con 0 genera un único fichero. Con N genera tantos ficheros como hagan falta: _001.sql, _002.sql… El ancho del sufijo se adapta al número total (3 dígitos mínimo).

La plantilla SQL se carga la primera vez que se ejecuta la opción 5 y se reutiliza en llamadas posteriores de la misma sesión. Cada fichero generado incluye una cabecera con metadatos: fecha, total de registros OK, número de fichero y modo de transacción.

Resultado: N ficheros .sql en disco listos para ejecutar en base de datos

Referencia rápida del menú

Produce: líneas añadidas al buffer interno. Muestra cuántas se añadieron y el total acumulado.

Produce: KO reparados → pasan a OK · Los que siguen fallando → nuevo CSV de errores en disco

Produce: uno o varios .sql en disco con cabecera de metadatos y sentencias INSERT listas para ejecutar

Muestra: líneas pendientes · registros OK · KO en memoria · modo de validación activo · columnas y separador de la config cargada

💡
Flujo habitual con errores — Opción 1 (carga CSV) → Opción 2 (carga JSON) → Opción 3 modo "solo campos" (sondeo rápido) → si hay KO por ; internos → Opción 4 (reparar) → Opción 3 modo completo → Opción 5 (generar SQL).
ℹ️
Encoding ANSI (Notepad++) — Notepad++ llama "ANSI" al encoding Windows-1252. Al pedir el encoding puedes escribir ansi, cp1252 o windows-1252: el motor los normaliza automáticamente y lo deja registrado en el log.
ℹ️
NULL en la plantilla SQL — Escribe los campos nullable entre comillas simples: '{ID_UNICO}'. El motor convierte el centinela interno en NULL (sin comillas) al escribir el SQL, tanto si aparece como 'NULL_SENTINEL' como sin comillas.
⚠️
Los datos en memoria son volátiles — Al cerrar el programa se pierde todo lo que no se haya escrito en disco. Los ficheros .sql, los CSV de errores y el log sí persisten. Si necesitas reanudar el proceso, vuelve a cargar solo los registros pendientes.

import re
import os
import csv
import logging
from datetime import datetime

#  Configuración de logging
# ─────────────────────────────────────────────
LOG_FILE = class="str">f"migracion_{datetime.now().strftime(class="str">'%Y%m%d_%H%M%S')}.log"

logging.basicConfig(
    level=logging.INFO,
    format=class="str">"%(asctime)s [%(levelname)s] %(message)s",
    handlers=[
        logging.FileHandler(LOG_FILE, encoding=class="str">"utf-8"),
        logging.StreamHandler()
    ]
)
log = logging.getLogger(__name__)

# Centinela interno para valores NULL.
# Se usa para distinguir un NULL real del string "null".
# En el SQL final se reemplaza por NULL (sin comillas).
_NULL_SENTINEL = class="str">"\x00NULL\x00"


# ─────────────────────────────────────────────
#  Motor principal
# ─────────────────────────────────────────────
class MotorMigracion:
    def __init__(self):
        # Líneas en bruto pendientes de validar (se acumulan entre cargas)
        self.datos_raw:     list[str]  = []
        self.config:        dict|None  = None
        # Registros ya validados correctamente, listos para exportar a SQL
        self.lineas_ok:     list[dict] = []
        # Registros KO de la última validación, pendientes de reparar
        self.lineas_ko:     list[dict] = []
        # Modo usado en la última validación (False=completa, True=solo campos)
        self.solo_campos:   bool       = False
        # Plantilla SQL cargada una vez por sesión
        self.plantilla_sql: str|None   = None

    # ──────────────────────────────────────────
    #  Menú
    # ──────────────────────────────────────────
    def menu(self):
        opciones = {
            class="str">"1": (class="str">"Ingesta de datos(CSV) — se acumula con pendientes",      self.ingesta_datos),
            class="str">"2": (class="str">"Carga plantilla de validación (JSON)",                    self.carga_plantilla),
            class="str">"3": (class="str">"Validación de datos",                                     self.validar_datos),
            class="str">"4": (class="str">"Reparar KO — re-parsear class="str">';' dentro de comillas",         self.reparar_ko),
            class="str">"5": (class="str">"Generación de SQLs",                                      self.generar_salida),
            class="str">"6": (class="str">"Resumen del estado actual",                               self.mostrar_resumen),
            class="str">"0": (class="str">"Salir",                                                   None),
        }

        while True:
            print(class="str">"\n╔══════════════════════════════════════╗")
            print(class="str">"║     MOTOR DE MIGRACIÓN UNIVERSAL     ║")
            print(class="str">"╚══════════════════════════════════════╝")
            for k, (desc, _) in opciones.items():
                print(class="str">f"  {k}. {desc}")

            opcion = input(class="str">"\nSelecciona una opción: ").strip()

            if opcion == class="str">"0":
                log.info(class="str">"Sesión finalizada por el usuario.")
                break
            elif opcion in opciones:
                opciones[opcion][1]()
            else:
                print(class="str">"❌ Opción no válida.")

    # ──────────────────────────────────────────
    #  1. Ingesta — ACUMULA, no reemplaza
    # ──────────────────────────────────────────
    def ingesta_datos(self):
        ruta = input(class="str">"Ruta del fichero CSV: ").strip()

        if not os.path.exists(ruta):
            log.error(class="str">f"Archivo no encontrado: {ruta}")
            return

        tiene_cabecera = input(class="str">"¿El CSV tiene cabecera? (s/n): ").strip().lower() == class="str">"s"
        encoding_raw   = input(class="str">"Encoding del fichero [utf-8] (ansi/cp1252/utf-8/iso-8859-1…): ").strip() or class="str">"utf-8"
        # ── Normalizar alias comunes ──────────────────────────────────────────
        _ALIAS = {
            class="str">"ansi":         class="str">"cp1252",
            class="str">"windows-1252": class="str">"cp1252",
            class="str">"win1252":      class="str">"cp1252",
            class="str">"cp1252":       class="str">"cp1252",
            class="str">"latin1":       class="str">"iso-8859-1",
            class="str">"latin-1":      class="str">"iso-8859-1",
            class="str">"iso-8859-1":   class="str">"iso-8859-1",
            class="str">"utf-8":        class="str">"utf-8",
            class="str">"utf8":         class="str">"utf-8",
        }
        encoding = _ALIAS.get(encoding_raw.lower(), encoding_raw)
        if encoding != encoding_raw:
            log.info(class="str">f"Encoding class="str">'{encoding_raw}' normalizado a class="str">'{encoding}'.")

        try:
            with open(ruta, class="str">"r", encoding=encoding) as f:
                lineas = [l.strip() for l in f if l.strip()]

            if tiene_cabecera and lineas:
                log.info(class="str">f"Cabecera ignorada: {lineas[0]}")
                lineas = lineas[1:]

            # ── ACUMULAR sobre las líneas pendientes existentes ──
            previas = len(self.datos_raw)
            self.datos_raw.extend(lineas)

            log.info(
                class="str">f"Añadidas {len(lineas)} líneas desde class="str">'{ruta}'. "
                class="str">f"Total pendientes: {len(self.datos_raw)} "
                class="str">f"(anteriores: {previas} + nuevas: {len(lineas)})."
            )
            self.mostrar_resumen()

        except Exception as e:
            log.error(class="str">f"Error al leer el fichero: {e}")

    # ──────────────────────────────────────────
    #  2. Carga plantilla JSON
    # ──────────────────────────────────────────
    def carga_plantilla(self):
        ruta = input(class="str">"Ruta del JSON de validación: ").strip()

        try:
            with open(ruta, class="str">"r", encoding=class="str">"utf-8") as f:
                config = json.load(f)

            if class="str">"columnas" not in config:
                raise ValueError(class="str">"El JSON debe contener la clave class="str">'columnas'.")
            for col in config[class="str">"columnas"]:
                if class="str">"nombre" not in col or class="str">"regex" not in col:
                    raise ValueError(class="str">f"Columna mal definida(falta class="str">'nombre' o class="str">'regex'): {col}")
                # 'nullable' es opcional; si no está, se asume False
                col.setdefault(class="str">"nullable", False)

            self.config = config
            sep = self.config.get(class="str">"separador", class="str">";")
            log.info(class="str">f"Plantilla cargada: {len(config[class="str">'columnas'])} columnas, separador=class="str">'{sep}'.")

        except Exception as e:
            log.error(class="str">f"Error al cargar JSON: {e}")

    # ──────────────────────────────────────────
    #  Validación interna de una línea
    # ──────────────────────────────────────────
    # ──────────────────────────────────────────
    #  Normalización de campo entrecomillado
    # ──────────────────────────────────────────
    @staticmethod
    def _normalizar_campo(valor: str, nombre_col: str, n_linea: int = 0) -> str:
        class="str">"""
        Si el campo empieza con comilla doble:
          · Con cierre → elimina ambas comillas y desdobla class="str">"" internas → "
          · Sin cierre → añade la comilla de cierre, luego aplica lo anterior
                         y registra un warning en el log.
        Si no empieza con comilla doble → devuelve el valor sin cambios.
        class="str">"""
        if not valor.startswith(class="str">'"'):
            return valor

        if valor.endswith(class="str">'"') and len(valor) >= 2:
            # Cierre presente → extraer contenido interior
            return valor[1:-1].replace(class="str">'class="str">""', class="str">'"')
        else:
            # Cierre ausente → autocorrección
            valor_corregido = valor[1:].replace(class="str">'class="str">""', class="str">'"')
            ref = class="str">f"línea {n_linea}, " if n_linea else class="str">""
            log.warning(
                class="str">f"Campo class="str">'{nombre_col}' ({ref}valor=class="str">'{valor}'): "
                class="str">f"comilla de cierre ausente — corregido automáticamente."
            )
            return valor_corregido

    def _validar_campos(self, campos: list[str], n_linea: int = 0,
                        solo_campos: bool = False) -> tuple[bool, dict | None, str]:
        class="str">"""
        Núcleo de validación — trabaja sobre una lista de campos YA PARTIDA.
        Llamado tanto por _validar_linea(split simple) como por reparar_ko
        (split consciente de comillas), evitando re-partir los campos.

        solo_campos=True  → solo verifica el número de columnas; almacena
                            valores tal cual(con escape SQL).
        solo_campos=False → validación completa: comillas, NULL, regex.
        class="str">"""
        columnas = self.config[class="str">"columnas"]

        if len(campos) != len(columnas):
            return (
                False, None,
                class="str">f"Se esperaban {len(columnas)} campos, se encontraron {len(campos)}"
            )

        # ── Modo solo campos ───────────────────────────────────
        if solo_campos:
            datos = {}
            for idx, col in enumerate(columnas):
                valor = campos[idx].strip()
                valor = self._normalizar_campo(valor, col[class="str">"nombre"], n_linea)
                es_nulo = valor == class="str">"" or valor.lower() == class="str">"null"
                datos[col[class="str">"nombre"]] = _NULL_SENTINEL if es_nulo else valor.replace(class="str">"class="str">'", class="str">"''")
            return True, datos, class="str">""

        datos = {}
        for idx, col in enumerate(columnas):
            valor    = campos[idx].strip()
            patron   = col[class="str">"regex"]
            nullable = col.get(class="str">"nullable", False)

            # ── Normalización de comillas dobles ───────────────
            valor = self._normalizar_campo(valor, col[class="str">"nombre"], n_linea)

            # ── Detección de NULL ──────────────────────────────
            es_nulo = valor == class="str">"" or valor.lower() == class="str">"null"

            if es_nulo:
                if nullable:
                    datos[col[class="str">"nombre"]] = _NULL_SENTINEL
                    continue
                else:
                    return (
                        False, None,
                        class="str">f"Campo class="str">'{col['nombreclass="str">']}' no permite NULL (nullable=false)"
                    )

            # ── Validación de regex ────────────────────────────
            if not re.fullmatch(patron, valor):
                return (
                    False, None,
                    class="str">f"Campo class="str">'{col['nombreclass="str">']}' no cumple regex({patron}): class="str">'{valor}'"
                )

            datos[col[class="str">"nombre"]] = valor.replace(class="str">"class="str">'", class="str">"''")

        return True, datos, class="str">""

    def _validar_linea(self, linea: str, n_linea: int = 0,
                       solo_campos: bool = False) -> tuple[bool, dict | None, str]:
        class="str">"""
        Parte la línea con split simple y delega en _validar_campos.
        Válido para líneas sin class="str">';' dentro de comillas.
        Para líneas con class="str">';' entre comillas usar reparar_ko(opción 4).
        class="str">"""
        sep    = self.config.get(class="str">"separador", class="str">";")
        campos = linea.split(sep)
        return self._validar_campos(campos, n_linea, solo_campos)

    # ──────────────────────────────────────────
    #  3. Validación
    #     · OK  → acumulados en self.lineas_ok
    #     · KO  → exportados a CSV de errores y purgados de datos_raw
    # ──────────────────────────────────────────
    def validar_datos(self):
        if not self.datos_raw:
            print(class="str">"❌ No hay líneas pendientes de validar. Carga un CSV (opción 1).")
            return
        if not self.config:
            print(class="str">"❌ Primero carga la plantilla JSON (opción 2).")
            return

        print(class="str">"\n  Modo de validación:")
        print(class="str">"    1. Completa   — número de campos + regex + nullable")
        print(class="str">"    2. Solo campos — únicamente verifica el número de columnas")
        modo_input = input(class="str">"\n  Selecciona modo [1]: ").strip() or class="str">"1"
        solo_campos = modo_input == class="str">"2"
        self.solo_campos = solo_campos   # recordar para reparar_ko

  async cargaPlantilla(ask) {
    const ruta = (await ask(class="str">'Ruta del JSON de validación: ')).trim();

      const config = JSON.parse(fs.readFileSync(ruta, class="str">'utf8'));

      if (!Array.isArray(config.columnas)) {
        throw new Error(class="str">"El JSON debe contener la clave class="str">'columnas' (array).");
      }
      for (const col of config.columnas) {
        if (!col.nombre || !col.regex) {

      }

  // ── NORMALIZACIÓN DE CAMPO ENTRECOMILLADO ──────────────────────────────────
  /**
   * Si el campo empieza con comilla doble:
   *   · Con cierre → elimina ambas comillas y desdobla class="str">"" internas → "
   *   · Sin cierre → añade la comilla de cierre y registra un warning.
   * Si no empieza con comilla doble → devuelve el valor sin cambios.
   */
  static normalizarCampo(valor, nombreCol, nLinea = 0) {
    if (!valor.startsWith(class="str">'"')) return valor;

    if (valor.endsWith(class="str">'"') && valor.length >= 2) {
      // Cierre presente → extraer contenido interior
      return valor.slice(1, -1).replace(/class="str">""/g, class="str">'"');
    } else {
      // Cierre ausente → autocorrección
      const corregido = valor.slice(1).replace(/class="str">""/g, class="str">'"');
      const ref = nLinea ? class=class="str">"str">`línea ${nLinea}, ` : class="str">'';
      log.warning(
        class=class="str">"str">`Campo class="str">'${nombreCol}' (${ref}valor=class="str">'${valor}'): ` +
        class=class="str">"str">`comilla de cierre ausente — corregido automáticamente.`
      );
      return corregido;
    }
  }

  // ── VALIDACIÓN INTERNA DE UNA LÍNEA ───────────────────────────────────────
  /**
   * @returns {[boolean, object|null, string]} [éxito, datos, motivo_error]
   *
   * Tratamiento de campos entrecomillados:
   *   · class="str">"valor"  → valor(comillas eliminadas, class="str">"" internas → ")
   *   · "valor   → valor(cierre añadido automáticamente + warning)
   *
   * Tratamiento de NULLs:
   *   · Vacío (class="str">"") o class="str">"null"/class="str">"NULL" + nullable=true → NULL_SENTINEL → SQL NULL
   *   · Vacío o class="str">"null"/class="str">"NULL" + nullable=false → KO
   *
   * Valores no nulos → escape SQL (comilla simple) antes de almacenar.
   */
  /**
   * Núcleo de validación — trabaja sobre una lista de campos YA PARTIDA.
   * Llamado tanto por _validarLinea(split simple) como por repararKo
   * (split consciente de comillas), evitando re-partir los campos.
   */
  _validarCampos(campos, nLinea = 0, soloCampos = false) {
    const columnas = this.config.columnas;

    if (campos.length !== columnas.length) {
      return [false, null,
        class=class="str">"str">`Se esperaban ${columnas.length} campos, se encontraron ${campos.length}`];
    }

    // ── Modo solo campos ──────────────────────────────────────────────────
    if (soloCampos) {
      const datos = {};
      for (let idx = 0; idx < columnas.length; idx++) {
        let valor = campos[idx].trim();
        valor = MotorMigracion.normalizarCampo(valor, columnas[idx].nombre, nLinea);
        const esNulo = valor === class="str">'' || valor.toLowerCase() === class="str">'null';
        datos[columnas[idx].nombre] = esNulo ? NULL_SENTINEL : valor.replace(/class="str">'/g, class="str">"''");
      }
      return [true, datos, class="str">''];
    }

    const datos = {};
    for (let idx = 0; idx < columnas.length; idx++) {
      const col      = columnas[idx];
      let   valor    = campos[idx].trim();
      const nullable = col.nullable ?? false;

      // ── Normalización de comillas dobles ──────────────────────
      valor = MotorMigracion.normalizarCampo(valor, col.nombre, nLinea);

      // ── Detección de NULL ─────────────────────────────────────
      const esNulo = valor === class="str">'' || valor.toLowerCase() === class="str">'null';
      if (esNulo) {
        if (nullable) { datos[col.nombre] = NULL_SENTINEL; continue; }
        else return [false, null, class=class="str">"str">`Campo class="str">'${col.nombre}' no permite NULL (nullable=false)`];
      }

      // ── Validación de regex ───────────────────────────────────
      const re = this._regexCache[col.nombre];
      if (!re.test(valor)) {
        return [false, null,
          class=class="str">"str">`Campo class="str">'${col.nombre}' no cumple regex(${col.regex}): class="str">'${valor}'`];
      }

      datos[col.nombre] = valor.replace(/class="str">'/g, class="str">"''");
    }

    return [true, datos, class="str">''];
  }

  /**
   * Parte la línea con split simple y delega en _validarCampos.
   * Válido para líneas sin class="str">';' dentro de comillas.
   * Para líneas con class="str">';' entre comillas usar repararKo(opción 4).
   */
  _validarLinea(linea, nLinea = 0, soloCampos = false) {
    const sep    = this.config.separador || class="str">';';
    const campos = linea.split(sep);
    return this._validarCampos(campos, nLinea, soloCampos);
  }

  // ── 3. VALIDACIÓN ─────────────────────────────────────────────────────────
  async validarDatos(ask) {

    console.log(class="str">'\n  Modo de validación:');
    console.log(class="str">'    1. Completa   — número de campos + regex + nullable');

  }

  // ── EXPORTAR CSV ERRORES ──────────────────────────────────────────────────
  /**
   * Genera un CSV con las líneas fallidas más la columna ERROR_CAUSA al final.
   * Timestamp en el nombre para no sobrescribir pasadas anteriores.
   */
  _exportarCsvErrores(lineasKo) {
    const sep      = this.config.separador || class="str">';';
    const columnas = this.config.columnas.map(c => c.nombre);
    const ts       = _tsFile();
    const ruta     = class=class="str">"str">`errores_${ts}.csv`;

    // N_LINEA primero para localizar rápidamente el error en el CSV original
    const filas = [columnas.concat(class="str">'N_LINEA', class="str">'ERROR_CAUSA').join(sep)];
    for (const ko of lineasKo) {
      const campos = ko.contenido.split(sep);
      while (campos.length < columnas.length) campos.push(class="str">'');
      filas.push(campos.concat(ko.nLinea, ko.motivo).join(sep));
    }
    fs.writeFileSync(ruta, filas.join(class="str">'\n'), class="str">'utf8');
    log.info(class=class="str">"str">`CSV de errores generado: class="str">'${ruta}' (${lineasKo.length} registros).`);
    return ruta;
  }


  // ── SPLIT CONSCIENTE DE COMILLAS ───────────────────────────────────────────
  /**
   * Divide la línea por el separador configurado, respetando los campos
   * entre comillas dobles(RFC 4180). Los class="str">';' dentro de class="str">'class="str">"..."' no cuentan
   * como separador — se conservan como parte del valor del campo.
   */
  _splitRespetandoComillas(linea) {
    const sep    = this.config.separador || class="str">';';
    const campos = [];
    let   campo  = class="str">'';
    let   inStr  = false;

    for (let i = 0; i < linea.length; i++) {
      const ch = linea[i];
      if (inStr) {
        if (ch === class="str">'"') {
          // Comilla de cierre (o "" interna → se conserva una)
          if (linea[i + 1] === class="str">'class="str">"') { campo += class="str">'"'; i++; }
          else inStr = false;
        } else {
          campo += ch;
        }
      } else {
        if (ch === class="str">'"') {
          inStr = true;
        } else if (ch === sep) {
          campos.push(campo); campo = class="str">'';
        } else {
          campo += ch;
        }
      }
    }
    campos.push(campo);
    return campos;
  }

  // ── 4. REPARAR KO ──────────────────────────────────────────────────────────
  /**
   * Lee un CSV de errores generado por este motor, re-parsea cada línea
   * usando split consciente de comillas(los class="str">';' dentro de class="str">'class="str">"..."' no
   * cuentan como separador) y vuelve a validar.
   *
   * · Líneas que ahora cuadran → validación completa → lineasOk
   * · Líneas que siguen fallando → nuevo CSV de errores
   */
  async repararKo() {
    if (!this.config) {
      console.log(class="str">'❌ Primero carga la plantilla JSON (opción 2).');
      return;
    }
    if (!this.lineasKo.length) {
      console.log(class="str">'❌ No hay líneas KO en memoria. Ejecuta primero la opción 3 (Validación).');
      return;
    }

    const sep   = this.config.separador || class="str">';';
    const nCols = this.config.columnas.length;

    const modoLabel = this.soloCampos ? class="str">'solo campos' : class="str">'completa';
    log.info(class=class="str">"str">`Reparando ${this.lineasKo.length} línea(s) KO — modo: ${modoLabel}.`);
    console.log(class=class="str">"str">`\n  Re-parseando ${this.lineasKo.length} línea(s) KO en memoria(modo ${modoLabel})...\n`);

    const nuevasOk = [];
    const siguenKo = [];

    for (const ko of this.lineasKo) {
      const { nLinea, contenido } = ko;
      // Usar split consciente de comillas y validar los campos directamente
      // sin reconstruir la línea (evita que ';' dentro de campos vuelvan a romper)
      const campos = this._splitRespetandoComillas(contenido);

      if (campos.length < nCols) {
        const motivo = class=class="str">"str">`Tras re-parseo: se esperaban ${nCols} campos, se encontraron ${campos.length}`;
        siguenKo.push({ nLinea, contenido, motivo });
        const msg = class=class="str">"str">`Línea ${nLinea} KO — ${motivo}`;
        console.log(class=class="str">"str">`  ❌ ${msg}`);
        log.warning(msg);
        continue;
      }

      // Descartar columnas extra del CSV de errores (N_LINEA, ERROR_CAUSA)
      const camposDatos = campos.slice(0, nCols);

      // Pasar los campos ya partidos directamente a _validarCampos
      const [exito, datos, motivo] = this._validarCampos(camposDatos, nLinea, this.soloCampos);
      if (exito) {
        nuevasOk.push(datos);
        log.info(class=class="str">"str">`Línea ${nLinea} reparada OK.`);
      } else {
        siguenKo.push({ nLinea, contenido, motivo });
        const msg = class=class="str">"str">`Línea ${nLinea} KO — ${motivo}`;
        console.log(class=class="str">"str">`  ❌ ${msg}`);
        log.warning(msg);
      }
    }

    this.lineasOk.push(...nuevasOk);
    // Actualizar lineasKo con solo los que siguen fallando
    this.lineasKo = siguenKo;

    if (siguenKo.length) {
      const rutaKo = this._exportarCsvErrores(siguenKo);
      console.log(class=class="str">"str">`\n⚠️  ${siguenKo.length} línea(s) siguen KO → class="str">'${rutaKo}'`);
    } else {
      console.log(class="str">'\n✅ Todas las líneas KO han sido reparadas.');
    }

    console.log(class=class="str">"str">`\n  Reparadas y OK     : ${nuevasOk.length}`);
    console.log(class=class="str">"str">`  Siguen KO          : ${siguenKo.length}`);
    console.log(class=class="str">"str">`  Total OK acumulados: ${this.lineasOk.length}`);
    this.mostrarResumen();
  }

  // ── 5. GENERACIÓN DE SQL ──────────────────────────────────────────────────
  async generarSalida(ask) {
    if (!this.lineasOk.length) {
      console.log(class="str">'❌ No hay datos validados para exportar.');
      return;
    }

    if (!this.plantillaSql) {
      const rutaP = (await ask(class="str">'Ruta de la plantilla SQL (.txt): ')).trim();
      if (!fs.existsSync(rutaP)) {
        log.error(class=class="str">"str">`Plantilla SQL no encontrada: ${rutaP}`);
        return;
      }
      try {
        this.plantillaSql = fs.readFileSync(rutaP, class="str">'utf8');
        log.info(class=class="str">"str">`Plantilla SQL cargada: class="str">'${rutaP}'.`);
      } catch (e) {
        log.error(class=class="str">"str">`Error al leer la plantilla SQL: ${e.message}`);
        return;
      }
    } else {
      log.info(class="str">'Reutilizando plantilla SQL de la sesión.');
    }

    const nombreBase = ((await ask(class="str">'Nombre base del fichero de salida [migracion_final.sql]: ')).trim())
      || class="str">'migracion_final.sql';

    // Separar nombre base y extensión para construir sufijo de secuencia
    const dotIdx = nombreBase.lastIndexOf(class="str">'.');
    const base   = dotIdx > 0 ? nombreBase.slice(0, dotIdx) : nombreBase;
    const ext    = dotIdx > 0 ? nombreBase.slice(dotIdx)    : class="str">'.sql';

    const batchRaw  = (await ask(class="str">'Tamaño de bloque(0 = sin transacción, N = COMMIT cada N filas): ')).trim();
    const batchSize = Math.max(0, parseInt(batchRaw, 10) || 0);

    const maxRaw   = (await ask(class="str">'Máximo de sentencias por fichero(0 = sin límite): ')).trim();
    const maxLineas = Math.max(0, parseInt(maxRaw, 10) || 0);

    // Sustitución de plantilla: reemplaza {CLAVE} con el valor del registro
    const _aplicarPlantilla = (plantilla, datos) =>
      plantilla.replace(/\{(\w+)\}/g, (match, clave) => {
        if (!(clave in datos)) throw new Error(class=class="str">"str">`Clave faltante en plantilla: ${clave}`);
        return datos[clave];
      });

    // Renderizado de NULLs: el centinela puede ir entre comillas o no
    const _renderNull = sql =>
      sql.split(class=class="str">"str">`class="str">'${NULL_SENTINEL}'`).join(class="str">'NULL')
         .split(NULL_SENTINEL).join(class="str">'NULL');

    try {
      // ── Precomputar todas las sentencias SQL válidas ──────────────────────
      const sentencias = [];
      let   omitidos   = 0;

      for (const d of this.lineasOk) {
        try {
          sentencias.push(_renderNull(_aplicarPlantilla(this.plantillaSql, d)));
        } catch (e) {
          log.warning(class=class="str">"str">`${e.message}. Registro omitido.`);
          omitidos++;
        }
      }

      const total      = sentencias.length;
      const nFicheros  = maxLineas > 0 ? Math.ceil(total / maxLineas) : 1;
      const anchura    = Math.max(3, String(nFicheros).length);
      const now        = new Date().toISOString().replace(class="str">'T', class="str">' ').slice(0, 19);
      const ficheros   = [];

      for (let nFich = 0; nFich < nFicheros; nFich++) {
        const inicio  = maxLineas > 0 ? nFich * maxLineas : 0;
        const fin     = maxLineas > 0 ? inicio + maxLineas : total;
        const bloque  = sentencias.slice(inicio, fin);
        const seq     = String(nFich + 1).padStart(anchura, class="str">'0');
        const nombreFich = nFicheros > 1 ? class=class="str">"str">`${base}_${seq}${ext}` : nombreBase;

        const lineas = [
          class=class="str">"str">`-- Migración generada : ${now}`,
          class=class="str">"str">`-- Registros OK       : ${total}`,
          class=class="str">"str">`-- Fichero            : ${nFich + 1} / ${nFicheros}`,
          class=class="str">"str">`-- Sentencias         : ${bloque.length}`,
          class=class="str">"str">`-- Modo transacción   : ${batchSize > 0 ? `batch de ${batchSize} filasclass=class="str">"str">` : class="str">'ninguna'}`,
          class="str">'',
        ];

        let batchLocal = 0;
        if (batchSize > 0) lineas.push(class="str">'BEGIN TRANSACTION;', class="str">'');

        for (const sql of bloque) {
          lineas.push(sql);
          batchLocal++;
          if (batchSize > 0 && batchLocal % batchSize === 0) {
            lineas.push(class="str">'', class=class="str">"str">`COMMIT; -- batch ${batchLocal / batchSize}`, class="str">'BEGIN TRANSACTION;', class="str">'');
          }
        }
        if (batchSize > 0) lineas.push(class="str">'', class="str">'COMMIT;');

        fs.writeFileSync(nombreFich, lineas.join(class="str">'\n'), class="str">'utf8');
        ficheros.push({ nombre: nombreFich, n: bloque.length });
        log.info(class=class="str">"str">`SQL generado: class="str">'${nombreFich}' (${bloque.length} sentencias).`);
      }

      if (omitidos) log.warning(class=class="str">"str">`${omitidos} registros omitidos por claves faltantes en la plantilla.`);

      console.log(class=class="str">"str">`\n🚀 Ficheros generados(${ficheros.length}):`);
      for (const { nombre, n } of ficheros) {
        console.log(class=class="str">"str">`   ${nombre}  (${n} sentencias)`);
      }
      console.log(class=class="str">"str">`📋 Log de sesión    : class="str">'${LOG_FILE}'`);
    } catch (e) {
      log.error(class=class="str">"str">`Error al generar el SQL: ${e.message}`);
    }
  }

  // ── 5. RESUMEN ────────────────────────────────────────────────────────────
  mostrarResumen() {
    console.log(class=class="str">"str">`\n${class="str">'─'.repeat(42)}`);
    console.log(class=class="str">"str">`  ⏳ Pendientes de validar : ${this.datosRaw.length}`);
    console.log(class=class="str">"str">`  ✅ Validados (OK)        : ${this.lineasOk.length}`);
    console.log(class=class="str">"str">`  ❌ KO en memoria         : ${this.lineasKo.length}`);
    console.log(class=class="str">"str">`  🔍 Modo validación       : ${this.soloCampos ? class="str">'solo campos' : class="str">'completa'}`);
    if (this.config) {
      console.log(class=class="str">"str">`  Columnas                 : ${this.config.columnas.length}`);
      console.log(class=class="str">"str">`  Separador                : class="str">'${this.config.separador || ';class="str">'}'`);
    }
    console.log(class="str">'─'.repeat(42));
  }
}
