Present Simple — describir cómo funciona algo
Estructura: Subject + verb + object
This service handles authentication.
Este servicio gestiona la autenticación.
The pipeline runs every time we push to main.
El pipeline se ejecuta cada vez que pusheamos a main.
Angular uses dependency injection to provide services.
Angular usa inyección de dependencias para proveer servicios.
SonarQube analyzes the code and reports code smells.
SonarQube analiza el código y reporta code smells.
This method returns a list of users.
Este método retorna una lista de usuarios.
The @Component decorator defines the metadata.
El decorador @Component define los metadatos.
Present Continuous — lo que pasa ahora
Estructura: Subject + am/is/are + verb-ing
I am working on the login feature.
Estoy trabajando en la funcionalidad de login.
The build is failing because of a dependency conflict.
El build está fallando por un conflicto de dependencias.
We are migrating from AngularJS to Angular 17.
Estamos migrando de AngularJS a Angular 17.
Jenkins is running the integration tests right now.
Jenkins está ejecutando los tests de integración ahora.
Past Simple — standups y commits
Estructura: Subject + verb-ed / irregular
I fixed the NullPointerException in UserService.
Arreglé el NullPointerException en UserService.
The deployment failed because the image was too large.
El despliegue falló porque la imagen era muy grande.
We refactored the component to use signals.
Refactorizamos el componente para usar signals.
I created a branch and pushed the changes.
Creé una rama y subí los cambios.
The test passed after I added the mock.
El test pasó después de que añadí el mock.
Modals — sugerir, pedir, obligar
should sugerencia
We should add unit tests before merging.
Deberíamos añadir tests unitarios antes de mergear.
could posibilidad
We could use a cache to improve performance.
Podríamos usar caché para mejorar rendimiento.
need to necesidad
We need to upgrade the Angular version.
Necesitamos actualizar la versión de Angular.
must obligación
This endpoint must validate the JWT token.
Este endpoint debe validar el token JWT.
might incertidumbre
The timeout might be causing the failures.
El timeout podría estar causando los fallos.
Conditionals & Passive
If + present → future
If we add an index, the query will be faster.
Si añadimos un índice, la query será más rápida.
If + past → would
If we used lazy loading, the bundle would be smaller.
Si usáramos lazy loading, el bundle sería más pequeño.
Passive
The request is validated by the middleware.
La request es validada por el middleware.
Passive
Tests are executed automatically by Jenkins.
Los tests son ejecutados automáticamente por Jenkins.
Passive
The bug was introduced in commit a3f29b1.
El bug fue introducido en el commit a3f29b1.

Dar feedback (tú revisas)
Regla de oro: Empieza positivo, luego sugiere. Usa could/should en vez de must.
Aprobar
Looks good to me! LGTM. Approved.
¡Me parece bien! Aprobado.
Elogiar
Nice approach! I like how you extracted the logic into a service.
Buen enfoque. Me gusta cómo extrajiste la lógica a un servicio.
Sugerir
What do you think about using a constant instead of a magic number?
¿Qué te parece usar una constante en vez de un número mágico?
Sugerir
Could we add a null check before calling this method?
¿Podríamos añadir un null check antes de llamar a este método?
Pedir cambio
This method is doing too much. Should we split it?
Este método hace demasiado. ¿Lo dividimos?
Bug potencial
This might cause a memory leak if we don't unsubscribe.
Esto podría causar un memory leak si no nos desuscribimos.
Tests
We need tests for this feature before merging.
Necesitamos tests para esta feature antes de mergear.

Aceptar
Good point! I'll fix that in the next commit.
Buena observación. Lo arreglo en el siguiente commit.
Aceptar

Lo hice así porque la API requiere el objeto completo.

Daily Standup — las 3 preguntas
DailyEstructura de tu standup
Yesterday I + past simple (lo que hiciste) Today I'm going to + infinitive (lo que harás) Blockers I'm blocked by / waiting for + noun
Ejemplo: "Yesterday I finished the login component and opened a PR. Today I'm going to start working on the user profile page. No blockers."
Con blocker: "Yesterday I worked on the payment integration but I got stuck with the API response format. Today I'm going to continue debugging. I'm blocked by the API team — I need the updated docs."
