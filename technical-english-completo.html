Present Simple — describir cómo funciona algo
Estructura: Subject + verb + object — Tu herramienta principal para explicar código y arquitectura.
This service handles authentication.
Este servicio gestiona la autenticación.
The pipeline runs every time we push to main.
El pipeline se ejecuta cada vez que pusheamos a main.
Angular uses dependency injection to provide services.
Angular usa inyección de dependencias para proveer servicios.
SonarQube analyzes the code and reports code smells.
SonarQube analiza el código y reporta code smells.
This method returns a list of users from the database.
Este método retorna una lista de usuarios de la base de datos.
The @Component decorator defines the metadata for the class.
El decorador @Component define los metadatos de la clase.
The controller receives the request and delegates to the service.
El controller recibe la request y delega al servicio.
Present Continuous — lo que pasa ahora mismo
Estructura: Subject + am/is/are + verb-ing — Para tareas en progreso y problemas actuales.
I am working on the login feature.
Estoy trabajando en la funcionalidad de login.
The build is failing because of a dependency conflict.
El build está fallando por un conflicto de dependencias.
We are migrating from AngularJS to Angular 17.
Estamos migrando de AngularJS a Angular 17.
Jenkins is running the integration tests right now.
Jenkins está ejecutando los tests de integración ahora.
The team is reviewing the new architecture proposal.
El equipo está revisando la propuesta de nueva arquitectura.
Past Simple — standups, commits, postmortems
Estructura: Subject + verb-ed / irregular — Para contar qué hiciste, qué pasó, qué cambió.
I fixed the NullPointerException in UserService.
Arreglé el NullPointerException en UserService.
The deployment failed because the image was too large.
El despliegue falló porque la imagen era muy grande.
We refactored the component to use signals instead of observables.
Refactorizamos el componente para usar signals en vez de observables.
I created a branch, pushed the changes and opened a PR.
Creé una rama, subí los cambios y abrí una PR.
The test passed after I added the mock for the HTTP client.
El test pasó después de que añadí el mock del HTTP client.
Yesterday I spent 3 hours debugging a race condition.
Ayer pasé 3 horas depurando una condición de carrera.
Modals — sugerir, pedir, obligar
Esenciales para code reviews y discusiones técnicas. Usa should/could para ser educado, must/need to para obligaciones.
should sugerencia educada
We should add unit tests before merging this PR.
Deberíamos añadir tests unitarios antes de mergear esta PR.
could posibilidad / propuesta
We could use Redis as a cache to improve response time.
Podríamos usar Redis como caché para mejorar el tiempo de respuesta.
need to necesidad clara
We need to upgrade the Angular version before adding signals.
Necesitamos actualizar la versión de Angular antes de añadir signals.
must obligación fuerte
This endpoint must validate the JWT token before processing.
Este endpoint debe validar el token JWT antes de procesar.
might incertidumbre
The timeout might be causing the intermittent failures.
El timeout podría estar causando los fallos intermitentes.
would hipótesis
That would break backward compatibility with v2 clients.
Eso rompería la compatibilidad con clientes de la v2.
Conditionals — si esto pasa, entonces...
If + present → future
If we add an index, the query will be 10x faster.
Si añadimos un índice, la query será 10x más rápida.
If + present → present
If the user is not authenticated, the guard redirects to login.
Si el usuario no está autenticado, el guard redirige al login.
If + past → would
If we used lazy loading, the initial bundle would be much smaller.
Si usáramos lazy loading, el bundle inicial sería mucho más pequeño.
Passive Voice — docs, tickets, commits
Muy común en documentación. El foco está en la acción, no en quién la hace. Patrón: Object + is/was + past participle.
The request is validated by the middleware before reaching the controller.
La request es validada por el middleware antes de llegar al controller.
Tests are executed automatically by Jenkins on every push.
Los tests son ejecutados automáticamente por Jenkins en cada push.
The bug was introduced in commit a3f29b1 and was fixed in b7c44d2.
El bug fue introducido en el commit a3f29b1 y arreglado en b7c44d2.
The config was updated in the last release to support Java 21.
La config fue actualizada en el último release para soportar Java 21.

Dar feedback — tú revisas una PR
Regla de oro: Empieza positivo → sugiere con could/should → pide cambios solo si es necesario. Nunca uses must salvo para seguridad.
Aprobar
Looks good to me! LGTM. Approved.
¡Me parece bien! Aprobado.
Elogiar
Nice approach! I like how you extracted the logic into a service.
Buen enfoque. Me gusta cómo extrajiste la lógica a un servicio.
Sugerir
What do you think about using a constant instead of a magic number?
¿Qué te parece usar una constante en vez de un número mágico?
Sugerir
Could we add a null check before calling this method?
¿Podríamos añadir un null check antes de llamar a este método?
Sugerir
I think this could be simplified by using Optional.ofNullable().
Creo que esto podría simplificarse usando Optional.ofNullable().
Pedir cambio
This method is doing too much. Should we split it into smaller ones?
Este método hace demasiado. ¿Deberíamos dividirlo?
Bug potencial
This might cause a memory leak if we don't unsubscribe here.
Esto podría causar un memory leak si no nos desuscribimos.
Tests
We need tests for this new feature before merging.
Necesitamos tests para esta feature antes de mergear.
Pregunta
I'm not sure I understand this logic. Could you add a comment explaining why?
No estoy seguro de entender esta lógica. ¿Podrías añadir un comentario?
Recibir feedback — te revisan a ti
Aceptar
Good point! I'll fix that in the next commit.
Buena observación. Lo arreglo en el siguiente commit.
Aceptar
You're right, I missed that edge case. Updating now.
Tienes razón, se me pasó ese edge case. Actualizando.
Explicar
I did it this way because the API requires the full object, not a partial one.
Lo hice así porque la API requiere el objeto completo.
Defender
That's intentional — the spec says we should return 204 here, not 200.
Es intencionado — la spec dice que debemos retornar 204, no 200.
Preguntar
Do you mean I should move this to the service layer?
¿Quieres decir que debería mover esto a la capa de servicio?
Commit messages — convención
Patrón universal: type(scope): description in imperative — Siempre en imperativo, como dando una orden al código.

fix(auth): validate token expiration before refresh
feat(catalog): add product search by category endpoint
refactor(checkout): extract payment logic into PaymentService
chore(ci): update Jenkins pipeline to use JDK 21
test(users): add unit tests for UserService edge cases
docs(readme): update setup instructions for local dev
Daily Standup — la estructura mágica
DailyLas 3 frases de tu standup
Yesterday I + past simple (lo que hiciste) Today I'm going to + infinitive (lo que harás) Blockers I'm blocked by / waiting for + noun (si tienes) No blockers. (si no tienes)
Ejemplo fluido:
"Yesterday I finished the login component and opened a PR. Today I'm going to start working on the user profile page. No blockers."
Ejemplo con blocker:
"Yesterday I worked on the payment integration but I got stuck with the API response format. Today I'm going to continue debugging the issue. I'm blocked by the API team — I need the updated documentation."
Planning, Retro & Estimaciones
Estimar
I think this is a 3-pointer. It's straightforward, just a CRUD.
Creo que es de 3 puntos. Es directo, solo un CRUD.
Dudar
I'm not sure about the complexity. Can we break it down into subtasks?
No estoy seguro de la complejidad. ¿Podemos partirlo en subtareas?
Dependencia
This story depends on the API being ready first.
Esta historia depende de que la API esté lista primero.
Coger tarea
I can take that story. I'll start tomorrow.
Puedo coger esa historia. Empiezo mañana.
Retro +
The deployment process was much smoother this sprint.
El proceso de deploy fue mucho más fluido este sprint.
Retro -
We should improve our code review turnaround time.
Deberíamos mejorar el tiempo de respuesta en reviews.
Proponer
What if we set a 24-hour SLA for reviewing PRs?
¿Y si ponemos un SLA de 24h para revisar PRs?
