Algoritmos clásicos — implementación en Java
Fórmula de Gauss Fácil O(1) tiempo · O(1) espacio
Suma de los primeros N números naturales. Útil para encontrar el elemento faltante en un array.
Código
public int elementoFaltante(int[] A) {
    int n = A.length;
    long esperada = (long)(n + 2) * (n + 1) / 2;
    long real = 0;
    for (int x : A) real += x;
    return (int)(esperada - real);
}
Ejemplo
A = [2, 3, 1, 5]
n = 4
esperada = (6*5)/2 = 15
real     = 2+3+1+5 = 11
resultado = 15 - 11 = 4 ✓
Búsqueda Binaria Medio O(log N) tiempo · O(1) espacio
Busca un elemento en un array ordenado, dividiendo el espacio de búsqueda a la mitad en cada paso.
Código
public int busquedaBinaria(int[] A, int target) {
    int izq = 0, der = A.length - 1;
    while (izq <= der) {
        int mid = izq + (der - izq) / 2;
        if (A[mid] == target)
            return mid;
        else if (A[mid] < target)
            izq = mid + 1;
        else
            der = mid - 1;
    }
    return -1; // no encontrado
}
Ejemplo
A      = [1,3,5,7,9]
target = 7

paso 1: mid=2, A[2]=5 < 7 → izq=3
paso 2: mid=4, A[4]=9 > 7 → der=3
paso 3: mid=3, A[3]=7 ✓
retorna índice 3
Two Pointers Medio O(N) tiempo · O(1) espacio
Dos punteros que avanzan desde los extremos. Útil para problemas de pares con suma objetivo, palíndromos, inversiones.
Código — par con suma K
public boolean parConSuma(int[] A, int K) {
    // Array debe estar ordenado
    int izq = 0, der = A.length - 1;
    while (izq < der) {
        int suma = A[izq] + A[der];
        if (suma == K)  return true;
        if (suma <  K)  izq++;
        else            der--;
    }
    return false;
}
Código — invertir array
public void invertir(int[] A) {
    int izq = 0, der = A.length - 1;
    while (izq < der) {
        // swap
        int tmp = A[izq];
        A[izq] = A[der];
        A[der] = tmp;
        izq++; der--;
    }
}
Sliding Window Medio O(N) tiempo · O(1) espacio
Una ventana deslizante de tamaño K que avanza por el array. Útil para máximos/mínimos en subarrays, sumas, medias móviles.
Código — suma máxima de K elementos
public int sumaMaxima(int[] A, int K) {
    int suma = 0;
    // primera ventana
    for (int i = 0; i < K; i++)
        suma += A[i];
    int max = suma;
    // deslizar ventana
    for (int i = K; i < A.length; i++) {
        suma += A[i] - A[i - K];
        max = Math.max(max, suma);
    }
    return max;
}
Ejemplo
A = [2,1,5,1,3,2], K=3

ventana 1: [2,1,5] suma = 8
ventana 2: [1,5,1] suma = 7
ventana 3: [5,1,3] suma = 9 ← max
ventana 4: [1,3,2] suma = 6

resultado: 9

Prefix Sum — Sumas prefijo Medio O(N) preproceso · O(1) consulta
Precalcular sumas acumuladas para responder consultas de suma de subarrays en O(1). Muy frecuente en Codility.
// Construir array de prefijos
int[] prefix = new int[A.length + 1];
for (int i = 0; i < A.length; i++)
    prefix[i + 1] = prefix[i] + A[i];

// Suma del subarray A[l..r] en O(1)
int sumaRango(int l, int r) {
    return prefix[r + 1] - prefix[l];
}
// Ejemplo: A=[1,2,3,4,5], suma A[1..3] = prefix[4]-prefix[1] = 10-1 = 9
Conteo con HashMap Fácil O(N) tiempo · O(N) espacio
Contar frecuencias de elementos. Patrón base para detectar duplicados, mayorías y equilibrios.
// Contar cuántas veces aparece cada número
HashMap<Integer,Integer> freq = new HashMap<>();
for (int n : A)
    freq.put(n, freq.getOrDefault(n, 0) + 1);

// ¿Hay algún elemento que aparezca más de una vez?
for (int v : freq.values())
    if (v > 1) return true;

// Alternativa con HashSet (más rápida para solo detectar duplicados)
HashSet<Integer> vistos = new HashSet<>();
for (int n : A)
    if (!vistos.add(n)) return false; // duplicado
Rotación de Array Fácil O(N) tiempo · O(N) espacio
Desplazar todos los elementos K posiciones a la derecha. Clave: K % N evita rotaciones innecesarias.
public int[] rotar(int[] A, int K) {
    int n = A.length;
    K = K % n;                             // evitar vueltas completas
    if (K == 0) return A;
    int[] res = new int[n];
    int[] izq = Arrays.copyOfRange(A, 0, n-K);    // parte izquierda
    int[] der = Arrays.copyOfRange(A, n-K, n);   // parte derecha (va al frente)
    System.arraycopy(der, 0, res, 0,   K);
    System.arraycopy(izq, 0, res, K, n-K);
    return res;
}
// A=[3,8,9,7,6], K=3 → [9,7,6,3,8]

💡 Consejos para Codility
Usa long en lugar de int cuando N puede ser grande para evitar overflow. Siempre maneja el caso de array vacío o N=0. Piensa primero en la complejidad: Codility penaliza soluciones O(N²) cuando existe una O(N). Puedes tener el navegador abierto con la documentación de Java.
